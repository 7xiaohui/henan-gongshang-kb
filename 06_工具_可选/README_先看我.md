## 环境

- **Python 3.9 或更高**
- 只有 `extract_all.py` 需要第三方库：`pip install pymupdf python-docx`
- 另外三个脚本**不依赖任何第三方库**，装个 Python 就能跑

Windows 上如果 `python` 不认，试试 `py`。

---

## 六个脚本各干什么

| 脚本 | 一句话 | 需要第三方库 |
|---|---|---|
| `card_qc.py` | 卡片结构质检：11 行连续表、标题白名单、编号连续、免责声明、出处可点、死链 | 否 |
| `check_cards.py` | 正向核对：卡片里每个"文号 + 条号"，在这份条文文本里到底存不存在 | 否 |
| `reverse_check.py` | 反向核对：哪些原件一张卡都没引用（要么白买，要么卡漏了内容） | 否 |
| `extract_all.py` | 原件 → 条文 md：认条、切条、四道校验 | 是 |
| `clean_output.py` | 清理模型输出里的 `[cite:...]`、过程话、"知识库"字样 | 否 |
| `_common.py` | 公共模块，负责找目录。**不用单独运行** | — |

## 对着本包怎么跑

先 `cd` 到本包根目录（就是有 `00_先读我.md` 的这一层），然后：

```bash
# 0. 清理模型输出（可选）
python 06_工具_可选/scripts/clean_output.py 原始回答.md 清理后.md

# 1. 卡片质检（最常用，改完卡就跑一次）
python 06_工具_可选/scripts/card_qc.py --root .

# 2. 正向核对（报告写到 out/ 目录）
python 06_工具_可选/scripts/check_cards.py --root .

# 3. 反向核对（列出零引用原件）
python 06_工具_可选/scripts/reverse_check.py --root .
```

`--root .` 就是"以当前目录为知识库根"。

> 脚本只扫 `03_权威资料/` **根层 54 份**；`条文文本/`（43 份抽取文本）和 `计发基数文件/`（7 份数据文件）两个子目录不参与核对。

**本包实测结果**（你跑出来应该一样）：

| 脚本 | 结果 |
|---|---|
| `card_qc.py` | 通过 38 / 38 |
| `check_cards.py` | ✅ 存在 414 ｜ ❌ 不存在 0 ｜ ⚠️ 待人工 217 |
| `reverse_check.py` | 零引用 3 份：`C10_工伤一件事实施方案` / `D5_补充工伤保险合作协议模板` / `D6_基本工伤补充保险缴费及赔付项目标准` —— 属背景与模板材料，正常 |

⚠️ **`extract_all.py` 会覆盖 `03_权威资料/条文文本/`**。只想试试的话，先把输出指到别处：

```bash
python 06_工具_可选/scripts/extract_all.py --root . --out "C:/temp/try-out"
```

## 目录名不用管

脚本**只认角色，不认名字**。下面两种写法都能自动识别：

```
本包形态                    原工作区形态
01_规则前置/                A_前置规则/
02_知识卡片/                B_知识卡片/
03_权威资料/                C_权威资料/1原始资料/
03_权威资料/条文文本/       C_权威资料/2抽取MD条文/
```

换成你自己的目录名也行，只要名字在候选表里（改 `_common.py` 顶部 `CANDIDATES` 即可）。找不到目录时脚本会**报错并列出实际目录**，不会猜一个凑合用。

---

## 三条必须知道的边界

1. **脚本只查"有没有"，不查"对不对"。**
   `check_cards.py` 能告诉你"第 22 条存在"，但**不能**告诉你"这张卡把第 22 条理解对了"。
   含义核对只能人读原文——这一步省不掉。

2. **改完卡必须重跑测试。**
   卡片内容是喂给 AI 的材料，改一句就可能改变回答。`04_使用说明/D2` 那 100 道题就是干这个的。

3. **⚠️ 待人工 ≠ 有问题。**
   `check_cards.py` 会留 200 多条"待人工"，多数是简称识别不出（比如卡片写"55 号令"，文件名里写"人社部令第55号"）。
   想减少这类，做一份 `aliases.json` 简称表即可，格式见 GitHub 仓库的 `examples/aliases.示例.json`。
