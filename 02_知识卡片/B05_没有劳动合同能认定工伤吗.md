# 没有劳动合同能认定工伤吗

| 字段       | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | **能。** 工伤认定看的是**有没有劳动关系**，不是**有没有合同**。<br />《劳动合同法》第 7 条：**用人单位自用工之日起即与劳动者建立劳动关系**——**书面合同只是证明方式之一，不是成立条件**。<br />没有合同的三条路：**① 用工资流水、考勤、工牌、工作群、同事证言等材料直接证明事实劳动关系**（多数情况够用）；**② 用人单位否认时，申请劳动仲裁"确认劳动关系"**，拿到裁决书再申请认定；**③ 关键在于——为确认劳动关系打仲裁花掉的时间，法律上不计入 1 年工伤认定申请期限**（人社部发〔2016〕29 号第八项第（四）项）。<br />所以真正的风险不是"没合同"，而是**没合同就一直干等、什么也不做，把一年等过去**。                                                                                                                                                           |
| **依据**   | 《劳动合同法》**第 7 条**（用工之日起建立劳动关系）、**第 10 条**（应订立书面合同，但不影响已建立的事实）。<br />《工伤保险条例》**第 18 条第 1 款第（二）项**（申请材料：**与用人单位存在劳动关系（包括事实劳动关系）的证明材料**——"包括事实劳动关系"这五个字是法律给你的门）。<br />《关于确立劳动关系有关事项的通知》（**劳社部发〔2005〕12 号**）**第一项**（无书面合同时认定劳动关系的三要件）、**第二项**（可作凭证的 5 类材料 + 用人单位的举证责任）。<br />《关于执行〈工伤保险条例〉若干问题的意见（二）》（**人社部发〔2016〕29 号**）**第八项第（四）项**（**就确认劳动关系申请劳动仲裁或提起民事诉讼的时间，不计入工伤认定申请时限**）。<br />《河南省工伤保险条例》（2026）**第 19 条**（申请材料）、**第 26 条**（中止情形）。                                                                   |
| **适用条件** | 已发生事故伤害或被诊断为职业病；**事实上在为单位提供劳动**（受单位管理、拿单位报酬、干单位的事）；尚未超过 1 年申请期限（或超期但存在不计入的法定情形）。<br />**典型场景**：小厂、工地、餐饮、快递、保安、家政、装修、临时工、试用期未签合同、单位只让签"劳务协议/承揽协议/合作协议"。                                                                                                                                                                                                                                                                                                                                                |
| **计算口径** | 不直接涉及金额，但决定你能走多远的三本账：<br />· **事实劳动关系三要件**（劳社部发〔2005〕12 号第一项，须**同时**具备）：① 单位和劳动者**符合法律法规规定的主体资格**；② 单位依法制定的**各项劳动规章制度适用于劳动者，劳动者受单位的劳动管理，从事单位安排的有报酬的劳动**；③ 劳动者提供的劳动**是单位业务的组成部分**。<br />· **1 年时限的扣除**：申请仲裁确认劳动关系的**全流程时间不计入**（29 号文第八项第（四）项），从仲裁申请日到裁决生效日都算。<br />· **举证责任倒置（仅限三项）**：单位否认劳动关系时，**只有第（一）项工资支付凭证/社保记录、第（三）项招工招聘登记表/报名表、第（四）项考勤记录**这三类凭证**由用人单位负举证责任**（劳社部发〔2005〕12 号第二项末句原文："其中，（一）、（三）、（四）项的有关凭证由用人单位负举证责任"）。**第（二）项身份证件、第（五）项证人证言不在单位举证范围内，要你自己举。** 单位拿不出前三项，承担不利后果。 |
| **易错点**  | ① **以为"没合同就没戏"**——错。条例第 18 条原文就写了"**包括事实劳动关系**"，这是法定受理范围。<br />② **没合同还傻等，把 1 年等过去**——这才是真正致命的。**没合同不是死路，干等一年不动作才是死路**（29 号文第八项已经给你开了口子）。<br />③ **被窗口一句"先去确认劳动关系"就撤件**——正确做法是**同时**：申请劳动仲裁 + 向人社局**书面申请中止**工伤认定程序（河南条例第 26 条列了中止情形）。**别撤件、别让时效白流。**<br />④ **只交"同事口头说我是他工友"**——证人证言要有**书面证言 + 证人身份证复印件 + 联系方式**，最好能出庭或接受电话核实。空口证言证明力弱。<br />⑤ **签了"劳务协议""承揽协议""合作协议"就以为不是劳动关系**——**看实质不看标题**。只要符合三要件（受管理、拿报酬、干单位业务的组成部分），名字叫"合作"也是劳动关系。<br />⑥ **忘了银行流水可以查**——微信/支付宝转账记录、银行代发工资记录都能调，很多单位正是通过这些被认定的。 |
| **待核实**  | ① ✅ **信阳市劳动人事争议仲裁委员会**：信阳市人社局 2 楼（新五大道 88 号）。立案窗口的具体收件清单仍需现场确认。<br />② 信阳工伤认定窗口**是否要求"必须先有确认劳动关系裁决书才受理"**（属地方土政策，法定不应作前置条件——条例第 18 条允许用"事实劳动关系证明材料"，不要求先仲裁）。<br />③ 河南"超龄人员/在校学生/平台骑手"的劳动关系认定最新口径（另见第 29、31、32 题）。                                                                                                                                                                                                                                                                                    |

## 展开说明

### 一、先把一句话钉死：法律要的是"劳动关系"，不是"劳动合同"

| 你的情况                           | 有劳动关系吗                    | 能认定工伤吗                  |
| ------------------------------ | ------------------------- | ----------------------- |
| 签了书面劳动合同                       | ✅ 有                       | ✅ 能                     |
| **没签合同，但正常上班、打卡、领工资**          | ✅ **有（事实劳动关系）**           | ✅ **能**                 |
| 签的是"劳务协议""合作协议""承揽协议"，但实际受管理   | ✅ **多半有**（看实质，不看标题）       | ✅ 能                     |
| 真的是按次结算的独立承揽（自己带工具、自己定时间、不受管理） | ❌ 一般没有                    | ❌ 不能（但可走人身损害赔偿，见第 27 题） |
| 单位找的是"包工头"，你在包工头手下干            | ⚠️ 复杂，可能找**用工单位**承担（见第五节） | ⚠️ 视情形                  |

> 《工伤保险条例》**第 18 条**原文要求提交的是：
>   
> "**与用人单位存在劳动关系（包括事实劳动关系）的证明材料**"
>
> 👉 **"包括事实劳动关系"这五个字，是国家条例里明明白白写的**。窗口如果说"没合同不受理"，是它没按条例办事，不是你没资格。

---

### 二、事实劳动关系怎么证明：三要件 + 五类凭证
#### 2.1 三要件（劳社部发〔2005〕12 号第一项），必须**同时**具备

| # | 要件                             | 说人话                                     | 怎么证明                  |
| - | ------------------------------ | --------------------------------------- | --------------------- |
| ① | 双方**符合法律法规规定的主体资格**            | 单位是合法登记的（有营业执照/依法成立），你年满 16 周岁、未达法定退休年龄 | 国家企业信用信息公示系统查单位；你的身份证 |
| ② | 你**受单位劳动管理**，从事**单位安排的有报酬的劳动** | 有人管你、给你派活、给你发钱                          | 打卡记录、排班表、领导微信派活、工资转账  |
| ③ | 你的劳动**是单位业务的组成部分**             | 你干的活就是这家单位赚钱的事                          | 单位经营范围、你的岗位说明、工作成果    |

> 🔴 **第 ② 条是主战场**。多数争议打的是"你到底受不受它管"。**谁给你派活、谁考核你、谁给你发钱——抓住这三条，基本就赢了一半。**
#### 2.2 五类凭证（劳社部发〔2005〕12 号第二项）

| # | 凭证                                       | 谁举证             | 实务提示                                    |
| - | ---------------------------------------- | --------------- | --------------------------------------- |
| 1 | **工资支付凭证或记录**（工资表、银行流水）、**缴纳各项社会保险费的记录** | **单位**（单位负举证责任） | 银行/微信/支付宝流水自己能打；**备注里出现"工资""薪资"字样的最有力** |
| 2 | **用人单位发放的工作证、服务证等身份证明**                  | 你               | 工牌、门禁卡、工装、员工手册、公司邮箱账号                   |
| 3 | **劳动者填写的用人单位招工招聘"登记表""报名表"**             | **单位**          | 入职填的那些表，单位拿不出来就吃不利后果                    |
| 4 | **考勤记录**                                 | **单位**          | 钉钉/企业微信打卡截图（**趁还能登录先截图保存**）             |
| 5 | **其他劳动者的证言**                             | 你               | 书面证言 + 证人身份证复印件 + 电话，**至少两人**           |

> 💡 **只有第 1、3、4 项由单位举证**——12 号文第二项末句原文写得极窄："**其中，（一）、（三）、（四）项的有关凭证由用人单位负举证责任**"。**第 2 项工牌、第 5 项证言不在其中，得你自己举。**
>   
> 这就是为什么"没合同"不可怕：**你能举的证不多，但单位要举的证不少。**

### 三、两条路：能直接认定，还是要先仲裁？

#### 3.1 路径对比

| 路径                    | 什么时候走                           | 时间成本                              | 风险                             |
| --------------------- | ------------------------------- | --------------------------------- | ------------------------------ |
| **路径 A：直接提交事实劳动关系材料** | 单位**不否认**你在这儿干活（只是不配合盖章、不承认是工伤） | 快，直接进工伤认定流程                       | 低。这是最理想的路                      |
| **路径 B：先仲裁确认劳动关系**    | 单位**明确否认**"你不是我们员工"             | 慢，仲裁一般 45 日、可延 15 日，加上送达/起诉可能半年以上 | 中。**但有法律兜底：这段时间不计入 1 年**（见第四节） |

#### 3.2 关键操作：**两条路可以同时走，但绝不能撤件**

正确的动作是三件事一起做：

```
第 1 步：照常向人社局递交工伤认定申请（材料里放事实劳动关系证据）
        ⚠️ 信阳认定窗口：市民之家社保窗口（羊山新区新七大道110号）
              ↓
第 2 步：如窗口表示"要先确认劳动关系"，立刻书面申请
        《中止工伤认定程序申请书》（河南条例第 26 条：中止情形）
              ↓
第 3 步：同时向劳动人事争议仲裁委员会申请《确认劳动关系》仲裁
        ⚠️ 信阳仲裁委：信阳市人社局 2 楼，新五大道 88 号
              ↓
仲裁裁决生效 → 把裁决书补交给人社局 → 恢复工伤认定程序
```

> 🔴 **最容易犯的错：听到"先去确认劳动关系"，就把工伤认定申请撤回来。**
>   
> **一旦撤回，时限怎么算就说不清了。正确做法是"申请中止"，不是"撤回"。**
>   
> 河南条例**第 26 条**列了中止情形，"需要以其他案件的审理结果为依据"是通行理由——确认劳动关系仲裁正好套这一条。

这是本库为这道题找到的最硬依据，出处是**人社部发〔2016〕29 号（意见二）第八项**：

### 四、⭐ 最重要的一条：仲裁期间**不计入** 1 年时限

这是本库为这道题找到的最硬依据，出处是**（意见二）第八项**：

> 由于不属于职工或者其近亲属自身原因超过工伤认定申请期限的，被延误的时间**不计算在工伤认定申请期限内**。有下列情形之一耽误申请时间的，应当认定为不属于职工或者其近亲属自身原因：
>   
> （一）受不可抗力影响的；
>   
> （二）职工由于被国家机关依法采取强制措施等人身自由受到限制不能申请工伤认定的；
>   
> （三）申请人正式提交了工伤认定申请，但因社会保险机构未登记或者材料遗失等原因造成申请超时限的；
>   
> **（四）当事人就确认劳动关系申请劳动仲裁或提起民事诉讼的；**
>   
> （五）其他符合法律法规规定的情形。

#### 4.1 打到你身上的效果

| 情形                                        | 1 年时限怎么算                                                          |
| ----------------------------------------- | ----------------------------------------------------------------- |
| 受伤后 4 个月申请仲裁确认劳动关系，打了 8 个月仲裁，第 12 个月拿到裁决书 | **这 8 个月不计入**。你还剩 8 个月可以申请工伤认定                                    |
| 受伤后一直没动作，第 13 个月才想起申请                     | ❌ 真的超期了。**没有"我不懂法"这一项**                                           |
| 单位口头说"公司会去报"，你干等一年                        | ❌ **不属于**这 5 种情形。**口头承诺不是"自身原因之外"的理由**（除非你能证明单位存在欺骗并导致你无法申请，个案判断） |

> 🔴 **一句话记住**：**"没合同"不是没有出路，而是必须先走"确认劳动关系"这一步——而这一步花掉的时间，法律上不算你超期。**
>   
> **真正致命的是：没合同 + 什么都不做 + 等一年。**

### 五、四种"卡人"的常见套路与破解

#### 套路 1：单位说"你是包工头找来的人，跟我们没关系"

| 判断                            | 结论                                                                                            |
| ----------------------------- | --------------------------------------------------------------------------------------------- |
| 包工头是**单位内部承包人/项目经理**，你干的是单位的活 | 一般认定**与单位**存在劳动关系                                                                             |
| 包工头是**独立承包人**，单位把工程合法分包给他     | 复杂：可主张**具备用工主体资格的发包方**承担工伤保险责任（最高法及人社部系列规定：违法转包、分包给不具备用工主体资格的组织或个人，由**具备用工主体资格的发包方**承担用工主体责任） |
| 单位**违法转包/分包**给自然人包工头          | ✅ 由**发包的单位**承担工伤保险责任                                                                          |

> 💡 **实操**：建筑工地受伤的，**把总包单位一起列为被申请人**，别只盯着包工头。包工头没钱赔，总包有钱。

- **申请仲裁后，直接要求单位举证**（工资支付凭证、招工登记表、考勤记录的举证责任在单位——劳社部发〔2005〕12 号第二项）。

- **看实质不看标题**。核心是**你有没有受它管理**：
  - 有固定上下班时间、要打卡、要请假 → 劳动关系
  - 用它的工具、在它的场地、穿它的工装 → 劳动关系
  - 按月固定发钱，而不是按成果一次性结算 → 劳动关系
- 反过来，如果你自己定时间、自己带工具、同时给多家干活、按次结算 → 可能真是承揽/劳务关系

#### 套路 3：单位否认，还把考勤和工资记录都删了

- **申请仲裁后，直接要求单位举证**（工资支付凭证、招工登记表、考勤记录的举证责任在单位——12 号文第二项）。
- 单位**无正当理由不提供**，仲裁庭可**采信你的主张**。
- 你自己能留的先留：**趁还能登录钉钉/企业微信，把打卡记录、排班表、工作群聊天记录全部截图**（并录屏，显示日期和账号）。

#### 套路 4：单位说"你试用期没签合同，不算"

- ❌ 试用期**包含在劳动合同期限内**（《劳动合同法》第 19 条第 4 款）。试用期一样是劳动关系，一样认定工伤。

### 六、行动清单（受伤后按这个顺序做）

```
【第 1 天 —— 越早越好】
□ 让医生在病历上写明"工作时受伤"及受伤经过
□ 现场拍照/录屏保存（监控一般只存 7–30 天，尽快找单位要）
□ 记下至少 2 位在场工友的姓名、电话、身份证号

【第 1 周】
□ 全部劳动关系证据截图/下载/打印，一式两份
   - 银行/微信/支付宝工资流水（能看出"工资"字样最好）
   - 钉钉/企业微信打卡记录（截图 + 录屏）
   - 工作群派活记录、领导微信
   - 工牌、工装、门禁卡、员工手册、公司邮箱
   - 入职时填的登记表（能拍到就拍）
□ 单位营业执照信息（国家企业信用信息公示系统免费查、免费下载打印）

【第 1 个月内】
□ 向人社局递交工伤认定申请（材料含事实劳动关系证据）
□ 如窗口要求先确认劳动关系 → 递交《中止工伤认定程序申请书》
□ 同时向劳动人事争议仲裁委员会申请确认劳动关系仲裁

【全程】
□ 每一次递交都要书面凭证：受理回执 / EMS 单号 / 网上申报截图
□ 不签任何"非工伤承诺书""自愿放弃""私了协议"
3. 为确认劳动关系打的仲裁时间，不计入 1 年申请期限（29 号文第八项第4项）

---

### 七、一页速查

```
【法律给你的三句话】
1. 没有合同 ≠ 没有劳动关系（劳动合同法第 7 条：用工之日起即建立）
2. 条例第 18 条原文就写了"包括事实劳动关系"——这是法定受理范围
3. 为确认劳动关系打的仲裁时间，不计入 1 年申请期限（29 号文第八项第4项）

【证明事实劳动关系的三要件（须同时）】
① 双方主体资格合法  ② 受单位管理 + 从事单位安排的有报酬劳动  ③ 是单位业务的组成部分

【五类凭证，其中三类由单位举证】
1 工资支付凭证、社保记录        ← 单位举证
2 工作证、服务证等身份证件       ← 你举证
3 招工招聘登记表、报名表         ← 单位举证
4 考勤记录                      ← 单位举证
5 其他劳动者的证言（≥2人）       ← 你举证

【千万别做】
✗ 听窗口说"先去确认劳动关系"就把工伤认定撤件（要"中止"，不要"撤回"）
✗ 干等一年不动作
✗ 签非工伤承诺书 / 自愿放弃 / 低价私了
```
