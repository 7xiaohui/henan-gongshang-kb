# 什么是工伤

| 字段 | 内容 |
|---|---|
| **结论** | **工伤不是"上班时受的伤"这么一句白话**，法律上是三类情形的合称：<br />① **应当认定为工伤**——在工作时间、工作场所内因工作原因受到事故伤害等 7 种（《工伤保险条例》第 14 条）；<br />② **视同工伤**——在工作岗位突发疾病 48 小时内死亡、抢险救灾受伤、退役军人旧伤复发 3 种（第 15 条）；<br />③ 以上两类若落入**故意犯罪 / 醉酒或吸毒 / 自残或自杀**，则**不得认定**（第 16 条）。<br />**核心判断标准是三个词：工作时间、工作场所、工作原因。** |
| **依据** | 《工伤保险条例》（国务院令第 586 号修订）**第 14、15、16 条**；《社会保险法》第 36 条；《河南省工伤保险条例》（2026）第 14、15、16 条（与国务院条例同文）。 |
| **适用条件** | 前提是存在**劳动关系（含事实劳动关系）**。没有劳动关系的，一般不走工伤，走人身损害赔偿；例外见河南新条例第 25 条（违法发包转包、个人挂靠经营，无劳动关系也可认定，由具备用工主体资格的单位担责）。<br />工伤是**无过错责任**——职工本人有过失（非故意）**不影响**认定。 |
| **计算口径** | 不涉及金额。但"是否认定为工伤"决定后续**全部待遇**：医疗费（基金支付，不能走医保）、停工留薪期工资、一次性伤残补助金、两项离职补助金等。<br />注意：**"视同工伤"中第 15 条第 3 项（退役军人旧伤复发）只享受除一次性伤残补助金以外的待遇**。 |
| **易错点** | ① **把"工伤"理解成"因公受的一切伤"**——法律是列举式，套不上就是套不上。<br />② **以为"自己不小心"就不算**——第 16 条只排三种，**没有"违章操作""过失"这一项**。<br />③ **以为"在单位出事就一定算"**——落入第 16 条三种情形照样不认。<br />④ **以为"上下班路上出事一律算"**——只有交通事故类且非本人主要责任才算。<br />⑤ **混淆"工伤"与"职业病"**——职业病是工伤的一种（第 14 条第 4 项），但要先取得职业病诊断证明书/鉴定书。 |
| **待核实** | ① 河南新条例第 58、59 条把**超龄劳动者**和**新就业形态人员（骑手/网约车/同城货运）**纳入保障，但**配套办法"另行制定"，截至 20261019 未见细则**——这两类人当前怎么认定，必须问当地窗口。<br />② 第 14 条第 7 项"法律、行政法规规定的其他情形"目前基本空置。 |
| **出处链接** | 《工伤保险条例》全文：<https://www.mohrss.gov.cn/wap/zc/fgwj/202011/t20201103_394950.html><br />《社会保险法》第 36 条：<https://www.mohrss.gov.cn/gjhzs/GJHZzhengcewenjian/201506/t20150625_212402.html><br />《河南省工伤保险条例》（2026）：<https://law.pkulaw.com/chinalaw/acfc133878ed991f28edee68a8cbbe6dbdfb.html> |

## 展开说明

### 一、一句话定义 + 一张图

> **工伤 = 因工作受到的伤害，由国家强制保险（工伤保险）赔付，不问职工有没有过错。**

```
你受伤了
   │
   ├─ 有劳动关系吗？ ──没有──→ 一般走「人身损害赔偿」（民法典侵权编）
   │        │有
   │        ↓
   ├─ 落入第16条三种排除吗？
   │        ├─是──→ 不认定（故意犯罪 / 醉酒吸毒 / 自残自杀）
   │        └─否
   │             ↓
   ├─ 套得上第14条 7 种？ ──是──→ 「应当认定为工伤」
   │        └─否
   ├─ 套得上第15条 3 种？ ──是──→ 「视同工伤」（第3项待遇打折）
   │        └─否
   └─→ 不予认定（可复议 / 诉讼）
```

### 二、四大特征（为什么工伤和普通赔偿不一样）

| 特征                | 含义                                          | 对你的意义                              |
| ----------------- | ------------------------------------------- | ---------------------------------- |
| **无过错责任**         | 不管职工有没有过失，只要符合法定情形就认                        | 单位说"你自己不小心"站不住（见 `B01_什么情况下算工伤.md`） |
| **法定项目、法定标准**     | 赔什么、赔多少，法律写死，不能协商打折                         | 单位"私了"报价常远低于法定标准                   |
| **基金支付 + 单位支付双轨** | 一部分钱基金出（医疗费、一次性伤残补助金），一部分单位出（停工留薪期工资、就业补助金） | 单位没参保 → **全部由单位按法定标准承担**           |
| **强制参保**          | 单位必须缴，职工个人不缴一分钱                             | "你自己去交工伤保险"是违法说法                   |

### 三、工伤 vs 医保 vs 商业意外险 vs 第三方赔偿（一张表分清）

|       | 工伤保险                                  | 基本医保         | 商业意外险          | 第三人侵权赔偿           |
| ----- | ------------------------------------- | ------------ | -------------- | ----------------- |
| 谁出钱   | 工伤保险基金 + 单位                           | 医保基金         | 保险公司           | 侵权人（肇事方等）         |
| 依据    | 《工伤保险条例》                              | 医保政策         | 保险合同           | 《民法典》侵权责任编        |
| 要不要认定 | **要**（工伤认定 + 劳动能力鉴定）                  | 不要           | 不要             | 不要（要定责）           |
| 赔多少   | **法定标准**，不可打折                         | 按目录、按比例      | **按保额**，看合同    | 按实际损失 + 责任比例      |
| 能否叠加  | 与商业险**可叠加**；与第三人赔偿**医疗费不重复、伤残待遇可并主张** | 工伤医疗费**不纳入** | 可叠加            | —                 |
| 常见误区  | 以为"单位赔了就行"                            | 以为"工伤也能刷医保"  | 以为"有意外险就不用报工伤" | 以为"拿了对方赔偿就不能再要工伤" |

> 详细展开见：`B15_工伤住院能用医保吗.md`、`B27_工伤赔偿和人身损害赔偿能同时要吗.md`

### 四、为什么必须先"认定"，不能私下算

很多人的损失就发生在这一步：

1. **不认定 → 没有《认定工伤决定书》→ 后续一切待遇都启动不了**（劳动能力鉴定要它、基金支付要它、仲裁要它）。
2. **单位"报销了医药费"≠ 认定工伤**。不给认定书，你的停工留薪期工资、伤残补助金、离职补助金全都无从主张。
3. **认定的举证责任在单位**（第 19 条第 2 款）：职工说是工伤、单位说不是，**由单位举证**。这是法律给职工的强保护——但前提是你得先把申请递上去。

### 五、"工伤"这个词在日常语境里的三种误用

| 日常说法               | 法律上是否准确                       |
| ------------------ | ----------------------------- |
| "我在单位搬东西闪了腰，算工伤吧？" | 要看是否满足"三工"（工作时间、场所、原因），多数情形算  |
| "我上下班路上摔了一跤，是工伤"   | ❌ 不算（非交通事故类，且本人责任）            |
| "我是职业病，不算工伤"       | ❌ 职业病**就是**工伤的一种（第 14 条第 4 项） |
