# 生活自理障碍等级是什么

| 字段 | 内容 |
|---|---|
| **结论** | 生活自理障碍等级是**工伤鉴定里的第二套结论**，和"伤残等级（一至十级）"**不是一回事**，专门用来决定**生活护理费**给不给、给多少。<br>**分三档**：**生活完全不能自理 / 生活大部分不能自理 / 生活部分不能自理**（没有"第四档"，也没有"0 级"）。<br>判断看**五项日常生活活动**：**进食、翻身、大、小便、穿衣洗漱、自主行动**。五项都不能自理 = **完全**；三至四项 = **大部分**；一至二项 = **部分**；五项全能自理 = **无护理依赖，不发护理费**。<br>**三档对应基金按月支付全省社平（河南现行 7,183.3 元/月）的 50% / 40% / 30%**，即 **3,591.65 / 2,873.32 / 2,154.99 元/月**。<br>**最关键一句**：**这项鉴定不会自动做，必须申请时明确提出，并拿到"经劳动能力鉴定委员会确认需要生活护理"的结论，否则没有护理费。** |
| **依据** | 《工伤保险条例》**第 22 条第 1 款**（劳动能力鉴定包括**劳动功能障碍程度**和**生活自理障碍程度**）、**第 34 条**（经确认需生活护理的，基金按月付；三档 50%/40%/30%）。<br>《河南省工伤保险条例》（2026）**第 34 条**（三档名称与比例，基数为**劳动能力鉴定结论作出时**全省上年度职工月平均工资）。<br>《劳动能力鉴定 职工工伤与职业病致残等级》（**GB/T 16180—2014**）**第 4.1.5 条**（生活自理范围五项 + 护理依赖程度三级，**本卡的直接依据，原文见下**）。<br>《劳动能力鉴定管理办法》（人社部令第 55 号，2025 施行）**第十五条**（鉴定依据即该国家标准）。<br>《河南省劳动能力鉴定委员会关于下放劳动能力鉴定事项及加强属地化管理的通知》（2025-12-28 印发，**2026-01-01 起执行**）：**生活自理障碍程度等级鉴定由各地市劳动能力鉴定委员会负责**。 |
| **适用条件** | ① **已被认定为工伤**；② **已评定伤残等级**（条例第 34 条要求"已经评定伤残等级**并**经确认需要生活护理"，两个条件并列）；③ 存在生活自理障碍的事实（进食/翻身/大小便/穿衣洗漱/自主行动受限）。<br>⚠️ **注意"并"字**：法条上护理费要求**先有伤残等级、再有护理确认**。实务中通常**同一次鉴定一并申请**两项结论。 |
| **计算口径** | **生活护理费（月） = 全省社平 × 比例**<br>· **完全不能自理 → 50% → 3,591.65 元/月**（年约 4.31 万）<br>· **大部分不能自理 → 40% → 2,873.32 元/月**（年约 3.45 万）<br>· **部分不能自理 → 30% → 2,154.99 元/月**（年约 2.59 万）<br>**基数时点 = 劳动能力鉴定结论作出时**的全省上年度职工月平均工资（河南条例第 34 条原文）。<br>**与伤残等级无关**：护理费不看你是几级伤残，只看生活自理障碍程度。八级伤残 + 部分护理依赖 → 有 30%；一级伤残 + 生活完全自理（罕见但可能）→ 无护理费。 |
| **易错点** | ① **把"伤残等级"当成"护理等级"**——**两套鉴定、两个结论、两笔钱**。伤残等级算一次性伤残补助金和伤残津贴；生活自理障碍等级算护理费。<br>② **评残时没提护理鉴定**——很多地方默认只出伤残等级结论，**护理等级要单独提出申请**。不提 = 没有 = 拿不到护理费。<br>③ **以为"一级伤残就一定有护理费"**——不一定。要看是否"生活不能自理"并经确认。<br>④ **以为护理费按本人工资算**——按**全省社平**，与本人工资无关。<br>⑤ **五项理解错误**——"不能自理"指**需要他人帮助才能完成**，不是"做起来费劲"。轻度受限一般够不上"部分不能自理"。<br>⑥ **出院后拖着不做鉴定**——生活自理障碍的判定要靠当时的病历、护理记录、功能评定。**时间越久越难举证。** |
| **待核实** | ① 信阳劳鉴委**是否支持"伤残等级 + 生活自理障碍"一次性一并申请**（多数地区支持，需窗口确认）。<br>② ✅ 已解决：生活自理障碍判定细则即 GB/T 16180—2014 **第 4.1.5 条**，原文已引入本卡第二节，见 `../03_权威资料/条文文本/GBT16180-2014_伤残等级国标_全文文本版.md`。<br>③ 河南是否有针对护理依赖程度的**定期复查**要求（部分省份要求每几年复核一次）。 |

## 展开说明

### 一、先把"两套鉴定"分清（这是本卡的第一要务）

| | **劳动功能障碍程度** | **生活自理障碍程度** |
|---|---|---|
| 俗称 | 伤残等级 | 护理等级 |
| 分几档 | **一至十级**（十档） | **三档**（完全 / 大部分 / 部分） |
| 判什么 | 器官缺损、功能障碍、医疗依赖 | **日常生活能不能自己完成** |
| 决定哪笔钱 | 一次性伤残补助金、伤残津贴、两项补助金 | **生活护理费** |
| 依据 | GB/T 16180—2014 | 条例第 22、34 条 + GB/T 16180—2014 |
| 出钱人 | 基金（伤残补助金）/ 基金或单位（津贴） | **基金**（未参保则单位） |

> 🔴 **最常见的误解**：*"我评了一级，护理费应该有吧？"*
> **不一定。** 一级伤残指的是**劳动功能障碍最重**（如双目失明、双上肢缺失等），但有些人虽然伤残极重、日常生活仍能通过辅助器具自理。**护理费要看五项活动，不看伤残等级。**

---

### 二、五项日常生活活动：判定的唯一标尺（GB/T 16180—2014 第 4.1.5 条原文）

生活自理范围主要包括下列五项（**标准原文表述**）：

| # | 项目 | 标准原文 |
|---|---|---|
| a) | **进食** | 完全不能自主进食，需依赖他人帮助 |
| b) | **翻身** | 不能自主翻身 |
| c) | **大、小便** | 不能自主行动，排大、小便需依靠他人帮助 |
| d) | **穿衣、洗漱** | 不能自己穿衣、洗漱，完全依赖他人帮助 |
| e) | **自主行动** | 不能自主走动 |

#### 2.1 三档的判定（标准原文）

**生活自理障碍程度分三级**：

| 等级 | 标准原文 | 比例 |
|---|---|---|
| **完全生活自理障碍** | 生活完全不能自理，上述**五项均需护理** | **50%** |
| **大部分生活自理障碍** | 生活**大部分**不能自理，上述**五项中三项或四项**需要护理 | **40%** |
| **部分生活自理障碍** | 生活**部分**不能自理，上述**五项中一项或两项**需要护理 | **30%** |
| （五项全能自理） | 无生活自理障碍 | **不发护理费** |

> 💡 **注意"大部分"不是"大部分时间"，而是"大部分项目"（五项中的 3–4 项）。** 这个措辞容易误解。
> ⚠️ **标准只规定"五项均需""五项中三项或四项""五项中一项或两项"三种情形**——**没有任何一项需要护理的，就不属于生活自理障碍**，无护理费。

#### 2.2 现行基数下的月金额

| 等级 | 比例 | 月金额（7,183.3 × 比例） | 年金额 |
|---|---|---|---|
| 完全不能自理 | 50% | **3,591.65 元** | 约 4.31 万元 |
| 大部分不能自理 | 40% | **2,873.32 元** | 约 3.45 万元 |
| 部分不能自理 | 30% | **2,154.99 元** | 约 2.59 万元 |

> ⚠️ 基数 = **劳动能力鉴定结论作出时**的全省上年度职工月平均工资（河南条例第 34 条）。
> 上表按现行基数 **7,183.3 元/月**（豫社保〔2025〕14 号）测算。**2026 年度计发文件截至 2026-10-19 未发布**，**7,585.25 元**系"就业人员"数折算——**2026 年度基数几乎可确定即为此数**，只差省社保中心发文；下发后重核补差。详见 `../01_规则前置/A1_口径基准.md` 第二节。

### 三、怎么申请（关键：**要主动提**）

#### 3.1 申请时机与方式

```
拿到《认定工伤决定书》
        ↓
治疗至伤情稳定 → 申请劳动能力鉴定
        ↓
★ 在申请表上同时勾选/写明：
   ① 劳动功能障碍程度等级鉴定（伤残等级）
   ② 生活自理障碍程度等级鉴定  ← 这一项很多人漏
        ↓
劳鉴委组织查体 → 出具结论书
   结论书应载明："伤残X级，生活自理障碍（无/部分/大部分/完全）"
        ↓
凭结论书向社保经办机构申领生活护理费
```

| **5（建议加）** | **护理相关证据**：住院护理记录、医嘱"需陪护"、护理等级评定单、出院记录中的自理能力评估 |

### 四、四个高频问题

**Q1：评了十级伤残，能有护理费吗？**
A：**通常没有**，但不是绝对。十级一般属"部分丧失劳动能力"，生活多能自理。**若确实存在一项以上自理障碍（如严重骨折后行动长期受限），可以申请生活自理障碍鉴定**，由鉴定委员会判。**不要自己先放弃。**

**Q2：护理费和伤残津贴、两项补助金能同时拿吗？**
A：**护理费与伤残津贴可以同时拿**（两笔不同性质的钱）。但与**两项补助金**的关系要注意：两项补助金是**解除/终止劳动关系**时的一次性待遇，护理费是**按月长期**待遇。**领了两项补助金后是否还保留护理费，须向窗口确认**（河南新条例第 38 条未再明写"工伤保险关系同时终止"，此处存疑，见 `B20_一次性工伤医疗补助金和就业补助金有什么区别.md` 待核实②）。

**Q3：护理等级会变吗？**
A：**会**。伤情好转或恶化，可申请**复查鉴定**。人社部发〔2025〕62 号明确：复查鉴定结论变化的，**伤残津贴、生活护理费按新结论调整**（但**一次性伤残补助金不调**）。

**Q4：护理费每年会涨吗？**
A：**会随待遇调整文件上调**。河南每年发《调整伤残津贴等工伤保险待遇》的通知（如 2025-09-30 那份）。上调是制度化动作，但**发现没调要主动问**。

### 五、一页速查

```
【两套鉴定，别混】
① 劳动功能障碍（伤残等级）一至十级 → 伤残补助金、伤残津贴、两项补助金
② 生活自理障碍 三档 → 生活护理费   ← 本卡

【三档判定（看五项里几项不能自理）】
进食 / 翻身 / 大小便 / 穿衣洗漱 / 自主行动
5项 → 完全不能自理 → 50% → 3,591.65 元/月
3-4项 → 大部分不能自理 → 40% → 2,873.32 元/月
1-2项 → 部分不能自理 → 30% → 2,154.99 元/月
0项 → 无护理依赖 → 不发

【关键动作】
□ 鉴定申请表上"一并"勾选生活自理障碍等级鉴定（不勾就没有）
□ 结论书要载明护理等级，否则回去要求补正
□ 基数用"鉴定结论作出时"的全省社平

【千万别做】
✗ 以为评了伤残就自动有护理费
✗ 以为护理费按本人工资算
✗ 出院太久了才想起来做鉴定（举证难）
```
