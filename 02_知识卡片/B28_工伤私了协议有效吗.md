# 工伤私了协议有效吗

| 字段       | 内容                                                                                                                                                                                                                                                                                                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | **"私了协议"不是一律有效，也不是一律无效**，关键看三点：<br />① **签的时候做没做工伤认定和伤残鉴定**——没做就签，通常构成**重大误解**或**显失公平**，可请求撤销；<br />② **金额是否明显低于法定标准**——明显偏低（实践中常以低于法定标准 50%–70% 为参考）可主张显失公平；<br />③ **有没有"自愿放弃工伤待遇""非工伤承诺书"这类条款**——这类条款通常无效，但**推翻要靠诉讼，成本很高**。<br />**一句话实务建议：先认定、再鉴定、算清数，最后才谈协议。顺序反了，签完再翻案极难。**                                                                                                    |
| **依据**   | 《民法典》**第 147 条**（重大误解）、**第 151 条**（显失公平）、**第 152 条**（撤销权行使期限：知道或应当知道撤销事由之日起 **1 年**内，最长不超过民事法律行为发生之日起 **5 年**）；《工伤保险条例》第 62 条第 2 款（未参保单位按条例标准支付）；《社会保险法》第 41 条；《劳动争议调解仲裁法》第 27 条（仲裁时效 1 年）。                                                                                                                                                                                         |
| **适用条件** | 用人单位与工伤职工（或其近亲属）就工伤待遇达成的**一次性了结协议**。<br />**不适用**：已经走完认定+鉴定，双方按法定标准或接近法定标准达成的和解——这种通常有效，且难以推翻。                                                                                                                                                                                                                                                                                      |
| **计算口径** | 判断"是否明显偏低"要有**参照系**：先把法定应得算出来（见 `B17_工伤十级伤残能拿多少赔偿.md`），再与协议金额比对。<br />**注意**：法定待遇是**法定项目、法定标准**，不因协议约定而消失；协议只是"债的处分"，不是"权利的创设"。                                                                                                                                                                                                                                                     |
| **易错点**  | ① **没做认定就签"两清"**——最常见、最吃亏。此时伤情、等级、金额全未知，属于典型的"重大误解"。<br />② **以为签了就彻底没救**——不是。可主张撤销，但**撤销权只有 1 年**（自知道或应当知道撤销事由起），且要打官司。<br />③ **协议里写"放弃一切权利主张"**——涵盖工伤保险待遇的放弃条款，多数法院不认可其效力；但**你要去打，才有意义**。<br />④ **单位口头承诺"后续再补"**——口头不算，协议写什么就是什么。<br />⑤ **以为劳动仲裁不受理"协议纠纷"**——因履行工伤待遇协议发生的争议属劳动争议，可以仲裁。                                                                                         |
| **待核实**  | ① **"明显偏低"的具体比例**：各地法院掌握不一，常见参考是"低于法定标准 50%–70%"，但**无统一规则**，属个案裁量。<br />② 河南本地对"未做鉴定的私了协议"的裁判倾向，需查本地判例（中国裁判文书网按"工伤 + 私了协议 + 显失公平"检索）。<br />③ 已领取的一次性待遇与协议金额冲抵规则，各地口径不一。                                                                                                                                                                                                             |

## 展开说明

### 一、三种协议，三种命运（先对号）

| 协议情形                         | 效力倾向               | 能不能翻                  |
| ---------------------------- | ------------------ | --------------------- |
| **A. 未认定、未鉴定就签"一次性了结"**      | 多数可撤销（重大误解 / 显失公平） | ⚠️ 能，但要打官司，且有 1 年撤销期限 |
| **B. 已认定已鉴定，金额明显低于法定标准**     | 可主张显失公平撤销          | ⚠️ 能，但需证明"明显偏低"       |
| **C. 已认定已鉴定，按法定标准或接近标准达成和解** | 通常有效               | ❌ 基本翻不了               |

> **关键分界线**：**"签的时候你知不知道自己的伤有多重、法定能拿多少"**。  
> 不知道 → 有撤销空间；知道 → 就是你自己处分权利，法律尊重。

### 二、单位最常用的五种话术（逐条拆）

| 话术                  | 真相                                                 |
| ------------------- | -------------------------------------------------- |
| "先签个字，钱马上给你"        | 签字即生效。**钱没到账别签。**                                  |
| "签了不影响你后面再要"        | 协议写"一次性了结""两清"，就是影响。**口头承诺无效。**                    |
| "你不签我们就走法律程序，拖你三年"  | 拖延确实是风险，但法定待遇不打折。**算清差额再决定。**                      |
| "你也有责任，只能给这么多"      | 工伤是**无过错责任**，"你有责任"在工伤认定里不成立（除非第 16 条三种情形）。        |
| "签个自愿放弃，我给你多缴几个月社保" | 放弃的是**两项补助金**（五至十级离职时合计可达 12–72 个月社平），多缴几个月社保远不能抵。 |

### 三、签之前必须核对的 6 件事

| # | 核对项                               | 为什么                                                         |
| - | --------------------------------- | ----------------------------------------------------------- |
| 1 | **工伤认定做了吗？**&#x62FF;到《认定工伤决定书》了吗？ | 没有认定书，后面一切待遇都启动不了                                           |
| 2 | **劳动能力鉴定做了吗？几级？**                 | 等级直接决定金额，没鉴定就谈钱等于闭眼签字                                       |
| 3 | **本人工资按什么口径算？**                   | 应按**月缴费工资**（受伤前 12 个月平均），不是实发、不是最低工资；单位少缴的可主张差额（河南条例第 46 条） |
| 4 | **两项补助金是不是两笔？**                   | 医疗补助金（基金付）+ 就业补助金（**单位付**），**不是二选一**                        |
| 5 | **距退休不足 5 年的递减算对了吗？**             | 每少 1 年递减 20%，**不足 1 年按 10%**。别被"差两年也按 10%"糊弄                |
| 6 | **停工留薪期工资、医疗费、护理费算进去了吗？**         | 这三项最容易在协议里被"打包忽略"                                           |

> 把这张表打印出来，对着协议一条条问。**问不清就先不签。**

### 四、已经签了，还有救吗

**有，但路窄、有时限、要花钱。** 三步：

1. **确认撤销事由**：是"重大误解"（当时不知道自己伤得多重 / 不知道法定标准）还是"显失公平"（金额明显偏低）？
2. **收集证据**：协议原件、认定书/鉴定书（若事后才做）、法定金额计算过程、单位沟通记录（微信/录音）、单位是否存在欺诈或胁迫。
3. **在期限内行动**：向**劳动人事争议仲裁委员会**申请仲裁（工伤待遇争议属劳动争议），或直接起诉主张撤销协议。
   - **撤销权期限：知道或应当知道撤销事由之日起 1 年内**（《民法典》第 152 条）；
   - **最长 5 年**（自民事法律行为发生之日起）；
   - **超过就是真的没救了。**

> ⚠️ 已签协议的翻案，**不建议自己上**。标的不小的，找当地法律援助（12348）或律师评估，成本远低于差额。

### 五、最省事的路：别让自己走到"要不要翻案"这一步

**正确顺序（背下来）**：

```
① 认定工伤  →  ② 伤情稳定后做劳动能力鉴定  →  ③ 按九项清单算清法定总额
                                                    ↓
                                        ④ 这之后，才谈协议 / 离职
```

**顺序反了会怎样**：先离职 → 单位翻脸 → 你没认定书、没鉴定、没算过账 → 只能接受它的报价，或者花一两年打官司。
