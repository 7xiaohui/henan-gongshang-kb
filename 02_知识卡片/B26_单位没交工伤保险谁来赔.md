## 展开说明

> 结论、依据、口径见文首表格；本节只写"为什么"和"实务中怎么操作"，不复述条文。

**单位没交工伤保险，待遇一分不少，只是出钱的人从"工伤保险基金"变成"用人单位"。**

法律依据很硬：《工伤保险条例》第 62 条第 2 款——

> 依照本条例规定应当参加工伤保险而未参加工伤保险的用人单位职工发生工伤的，**由该用人单位按照本条例规定的工伤保险待遇项目和标准支付费用**。

记住这句口诀：**标准不变，主体变更。**

---

### 一、先把三件事分清

很多人问"谁来赔"时，其实混了三种完全不同的情况：

| 情况                | 谁出钱                                                | 依据                   |
| ----------------- | -------------------------------------------------- | -------------------- |
| **A. 单位依法参保**     | 大部分由**工伤保险基金**出；停工留薪期工资、五六级伤残津贴、一次性伤残就业补助金由**单位**出 | 条例第 30、33、35、36、37 条 |
| **B. 单位应当参保但没参保** | **全部由单位出**，按条例项目和标准                                | 条例第 62 条第 2 款        |
| **C. 单位参保后又欠缴保费** | 欠缴期间发生工伤的，**先由基金支付**，基金再向单位追偿                      | 条例第 62 条第 3 款        |

**判断方法**：先查社保缴费记录（"河南人社"APP 或 12333 可查），确认你的工伤发生当月有没有参保记录。

---

### 二、情况 B：单位没参保，你能拿到哪些钱

**一项都不少。** 逐项对照如下：

| 待遇项目                         | 参保时谁出 | 未参保时谁出 | 备注                      |
| ---------------------------- | ----- | ------ | ----------------------- |
| 医疗费、康复费                      | 基金    | **单位** | 见 `B16_工伤医疗费怎么报能报哪些.md` |
| 住院伙食补助费                      | 基金    | **单位** |                         |
| 交通食宿费（经批准外出就医）               | 基金    | **单位** |                         |
| 辅助器具费                        | 基金    | **单位** |                         |
| 停工留薪期工资                      | 单位    | **单位** | 原工资福利待遇不变，按月发           |
| 停工留薪期护理                      | 单位    | **单位** |                         |
| 一次性伤残补助金                     | 基金    | **单位** | 一至十级都有，见口径基准月数表         |
| 一至四级伤残津贴                     | 基金    | **单位** | 按月发至退休                  |
| 五至六级伤残津贴（难安排工作时）             | 单位    | **单位** | 按月发                     |
| 一次性工伤医疗补助金                   | 基金    | **单位** | 五至十级解除/终止劳动关系时          |
| 一次性伤残就业补助金                   | 单位    | **单位** | 同上                      |
| 生活护理费                        | 基金    | **单位** | 经鉴定有生活自理障碍              |
| 工亡三项（丧葬补助金、供养亲属抚恤金、一次性工亡补助金） | 基金    | **单位** |                         |

**关键差异：拿到判决/裁决后能不能真拿到钱**

表上说"单位出"，但单位是私企、账上没钱、或者干脆注销了怎么办？这才是现实问题。所以下面第四节专门讲。

### 三、单位不付钱的四条路（按顺序走）

#### 第 1 步：书面要求（留证据）

**做什么**：给单位发一份《要求支付工伤保险待遇的函》，EMS 寄送，保留邮寄凭证和签收记录。  
**为什么**：这一步不是指望单位良心发现，而是**制造证据**——证明你主张过、单位拒绝过，后面仲裁时用得上。  
**写什么**：受伤时间、认定书文号、鉴定结论、应付款项明细（按口径基准算）、付款期限。

#### 第 2 步：申请工伤保险基金先行支付 ⭐ 最有用

**法律依据**：《社会保险法》第 41 条

> 职工所在用人单位未依法缴纳工伤保险费，发生工伤事故的，由用人单位支付工伤保险待遇。**用人单位不支付的，从工伤保险基金中先行支付**。从工伤保险基金中先行支付的工伤保险待遇应当由用人单位偿还。用人单位不偿还的，社会保险经办机构可以依照本法第六十三条的规定追偿。

**具体规则**：《社会保险基金先行支付暂行办法》（人社部令第 15 号，2018 修订）第 4、5、6 条。

**条件（三个都要满足）**：

1. 用人单位**未依法缴纳**工伤保险费
2. 已经发生工伤事故（须有《认定工伤决定书》）
3. **用人单位不支付**

**先行支付办法第 6 条列明的"单位不支付"情形**（符合任一即可申请）：

- 用人单位被依法**吊销营业执照**（或撤销登记、备案）的
- 用人单位**拒绝支付**全部或部分费用的
- 用人单位**未在限期内支付**的
- 依法应当由用人单位支付而用人单位**未依法支付**的其他情形

**经办机构必须走的时间线（第 5 条，这条你要知道，可以用来催）**：

```
经办机构收到申请
   ↓ 3 个工作日内
向用人单位发出书面催告通知
   ↓ 要求单位在 5 个工作日内支付
单位仍不支付
   ↓
经办机构【应当】用工伤保险基金先行支付
```

> ⚠️ **这是"应当"，不是"可以"。** 经办机构没有自由裁量权，条件符合就必须垫。如果不垫，属于不履行法定职责，可申请行政复议或提起诉讼。

**怎么申请**：

- 由工伤职工或其近亲属向**参保地社会保险经办机构**提出**书面**申请
- 材料：先行支付申请书、认定工伤决定书、劳动能力鉴定结论、单位不支付的证明（催告函 + EMS 邮寄凭证）
- 基金垫付后，由经办机构向单位追偿（不用你再去追）

⚠️ **重要限制**：单位**已参保**的，不适用先行支付。所以第 1 步查缴费记录很关键。

⚠️ **另一个常见误区**：先行支付**不限于医疗费**。第 6 条写的是"申请先行支付**工伤保险待遇**"，包括一次性伤残补助金等。但实务中各地执行尺度不一，**建议一并申请，被拒再主张**。

#### 第 3 步：劳动仲裁

**做什么**：向单位所在地或劳动合同履行地的**劳动人事争议仲裁委员会**申请仲裁。  
**时效**：1 年，从知道或应当知道权利被侵害之日起算（《劳动争议调解仲裁法》第 27 条）。  
**主张什么**：全部工伤保险待遇，按条例项目和标准逐项列明金额。  
**费用**：劳动仲裁**不收费**。  
**注意**：如果单位否认劳动关系，先打"确认劳动关系"的仲裁（见 `B05_没有劳动合同能认定工伤吗.md`）。

#### 第 4 步：法院

对仲裁裁决不服的，15 日内向人民法院起诉。  
单位不履行生效裁决/判决的，申请**强制执行**。

### 四、单位"跑路"了怎么办

这是最现实的问题。三种常见情形：

| 情形            | 应对                                                                  |
| ------------- | ------------------------------------------------------------------- |
| **单位还在，就是不付** | 走上面的四步，仲裁 + 强制执行                                                    |
| **单位注销了**     | 查工商档案，找**清算义务人**（股东、清算组成员）。未依法清算就注销的，股东对债务承担**清偿责任**。可向市场监管部门调取注销档案 |
| **单位是空壳、无财产** | 优先走**基金先行支付**（第 2 步），比追一个空壳公司现实得多                                   |

**实操提示**：仲裁时同步申请**财产保全**，防止单位转移资产。需要提供担保，但对有履行能力却恶意拖欠的单位很有效。

### 五、单位常见的五种说法

| 单位说法                | 真假         | 怎么应对                                              |
| ------------------- | ---------- | ------------------------------------------------- |
| "我们没交保险，所以不归工伤管"    | ❌ **假的**   | 条例第 62 条第 2 款直接打脸：没参保按条例标准由单位付                    |
| "没交保险就没有工伤认定"       | ❌ **假的**   | 工伤认定看的是**有没有劳动关系 + 是不是工伤**，与是否参保无关。社保部门必须受理       |
| "保险是你自己不愿意交的，签了放弃书" | ❌ **无效**   | 缴纳社保是**法定义务**，不能通过协议免除。放弃书无效，单位仍要赔                |
| "补缴了保险就由基金出"        | ⚠️ **部分真** | 条例第 62 条第 3 款：**补缴后新发生的费用**由基金支付，**补缴前已发生的仍由单位付** |
| "我们给你报了医疗费就行了"      | ❌ **不够**   | 医疗费只是九项待遇之一，还有伤残补助金、就业补助金、停工留薪期工资等                |

#### ⭐ "新发生的费用"到底包括哪些？—— 人社部有明确清单

单位最爱说"我们补缴了，剩下的找基金"。**补缴后基金到底管哪几项，人社部发〔2016〕29 号第三项写死了**：

> **因工受伤的**，基金支付参保后新发生的：  
> **① 工伤医疗费 ② 工伤康复费 ③ 住院伙食补助费 ④ 统筹地区以外就医交通食宿费 ⑤ 辅助器具配置费 ⑥ 生活护理费 ⑦ 一级至四级伤残职工伤残津贴 ⑧ 参保后解除劳动合同时的一次性工伤医疗补助金**
>
> **因工死亡的**，支付参保后新发生的**符合条件的供养亲属抚恤金**。

**反过来看更清楚——以下这些，基金一律不管，永远由单位掏：**

| 项目             | 谁付     | 为什么           |
| -------------- | ------ | ------------- |
| 补缴前已发生的全部费用    | **单位** | "新发生"三个字挡着    |
| **一次性伤残补助金**   | **单位** | ❗ 不在上面 8 项清单里 |
| **一次性伤残就业补助金** | **单位** | ❗ 本来法定就是单位付   |
| **停工留薪期工资**    | **单位** | 本来就不是基金项目     |
| 五、六级伤残津贴       | **单位** | 只有一至四级才由基金付   |

> 🔴 **这是本卡最值钱的一张表**：很多人被单位一句"我补缴了"糊弄过去，结果发现**最大那笔一次性伤残补助金仍然要单位付**——因为人社部的清单里根本没有它。  
> 谈判时可以直接说："人社部发〔2016〕29 号第三项列了 8 项，一次性伤残补助金不在里面。"

> ⚠️ **"补缴"还有一种情形**：单位**先参保后受伤**（正常参保）→ 全部由基金按规定支付，不适用本条。本条只管"**先受伤、后参保**"。

### 六、算一笔账：十级伤残、单位没参保

假设：信阳，本人工资 5,000 元/月，十级伤残，解除劳动关系，距退休还有 10 年以上。

| 项目            | 金额            | 计算                             |
| ------------- | ------------- | ------------------------------ |
| 一次性伤残补助金      | 35,000 元      | 5,000 × 7 个月（本人工资未低于下限，不封顶不保底） |
| 一次性工伤医疗补助金    | 43,099.8 元    | **7,183.3** × 6 个月             |
| 一次性伤残就业补助金    | 43,099.8 元    | **7,183.3** × 6 个月             |
| 停工留薪期工资       | 按实际月数 × 5,000 | 假设 3 个月 = 15,000 元             |
| 医疗费           | 按票据实报         | 假设 20,000 元                    |
| **合计（不含医疗费）** | **约 13.6 万元** |                                |

**如果单位参保**：基金出一次性伤残补助金 35,000 元 + 一次性工伤医疗补助金 43,099.8 元 + 医疗费；单位出一次性伤残就业补助金 43,099.8 元 + 停工留薪期工资 15,000 元。  
**如果单位没参保**：上述全部 **136,199.6 元**（不含医疗费）都由单位出。

> ⚠️ **基数用哪一年，取决于"哪一年解除劳动关系"**，不是受伤年份：
>
> - **现行有效基数：7,183.3 元/月**（豫社保〔2025〕14 号，核算 2025 年度）
> - **2026 年度计发文件截至 2026-10-19 未发布**；文件出台后若基数上调，已核定的要**重核补发差额**（历年文件都这么规定）
> - 按 91,023 元折算的 **7,585.25 元**（**几乎可确定就是 2026 年度基数**，只差发文；下发后重核补差）：两项各 45,511.5 元，合计 141,023 元

> ⚠️ 上述为示意算例，实际金额以你的本人工资、鉴定等级、解除时间、全省社平为准。基数口径见 `../01_规则前置/A1_口径基准.md`。
