# 什么情况下算工伤

| 字段       | 内容                                                                                                                                                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | 法律列了三档：**"应当认定为工伤"7 种**（《工伤保险条例》第 14 条）、**"视同工伤"3 种**（第 15 条）、**"不得认定"3 种**（第 16 条）。判断的核心是三个词：**工作时间、工作场所、工作原因**——三者在场即"应当认定"；不在场但有特别政策，走"视同"；在场但有法定排除情形，不认定。                                                                                                        |
| **依据**   | 《工伤保险条例》（国务院令第 586 号修订）第 14、15、16 条；《河南省工伤保险条例》（2026）第 14、15、16 条（与国务院条例同文）；《社会保险法》第 36 条。<br />**三要素官方口径：人社部发〔2025〕62 号第一至三项**（工作时间/工作场所/因工作原因）。<br />**单位组织活动与驻外：人社部发〔2016〕29 号（意见二）第四、五项**。                                                                       |
| **适用条件** | 见下方「三档全景表」。只要**发生劳动关系（含事实劳动关系）范围内的伤害**，且不属于第 16 条三种排除情形，就应当按这三档往里套。                                                                                                                                                                                                  |
| **计算口径** | 不涉及金额。但需注意：**"应当认定"与"视同工伤"待遇不同**——第 15 条第 3 项（退役军人旧伤复发）**只能享受除一次性伤残补助金以外的待遇**。                                                                                                                                                                                       |
| **易错点**  | ① 以为"在单位出事就一定算"——**第 16 条三种情形直接否掉**，哪怕三要素齐全。<br />② 以为"上下班路上出事一律算"——**只看交通事故类，且必须"非本人主要责任"**，自己摔伤、走路崴脚不算。<br />③ 把"视同工伤"和"应当认定"混为一谈，忽略了旧伤复发不享受一次性伤残补助金。                                                                                                              |
| **待核实**  | ① 河南新条例第 15 条把"48 小时"改为汉字"四十八小时"，实质未变，但**各地对"48 小时起算点"（初诊时间 vs 抢救开始时间）仍有分歧**，属司法认定问题，需按个案看判例。<br />② 第 14 条第 7 项"法律、行政法规规定应当认定为工伤的其他情形"目前无新增单行法，实际是兜底条款。                                                                                                             |

## 展开说明

### 一、三档全景表（一张表看全）

**第一档：应当认定为工伤（第 14 条，7 种）**

| # | 情形                                            | 关键判断点            | 实务中最常争的                    |
| - | --------------------------------------------- | ---------------- | -------------------------- |
| 1 | 工作时间 + 工作场所内 + **因工作原因**受到事故伤害                | 三个"工作"必须同时指向同一件事 | "工作原因"是否成立——干私活、串岗打闹受伤常有争议 |
| 2 | 工作时间**前后** + 工作场所内 + 从事**预备性或收尾性**工作受伤        | 提前到岗开机、下班后清理场地都算 | "预备/收尾"的边界：换工作服算不算？多数地方认为算 |
| 3 | 工作时间 + 工作场所内 + **因履行工作职责**受到暴力等意外伤害           | 暴力须与"履职"有因果关系    | 因私人恩怨被打，即便在岗也不算            |
| 4 | **患职业病**                                      | 须有职业病诊断证明书/鉴定书   | 诊断机构资质；《职业病分类和目录》范围内       |
| 5 | **因工外出期间** + 因工作原因受伤 / 发生事故下落不明               | 外出须因公（有派工、出差审批等） | 出差期间晚上外出吃饭、娱乐受伤，各地认定不一     |
| 6 | **上下班途中** + **非本人主要责任**的交通事故（含城市轨道交通、客运轮渡、火车） | 需交警《道路交通事故认定书》   | "合理路线""合理时间"；本人主要责任即不认     |
| 7 | 法律、行政法规规定的其他情形                                | 兜底               | 目前基本空置                     |

> **一句话记法**：第 1 项是主干，第 2、3 项是它的两个扩展（时间前后延、原因扩到暴力），第 4、5、6 项是三类"不在典型岗位现场但仍算"的特别情形。

### ⭐ "工作时间 / 工作场所 / 因工作原因"到底怎么算（2025 年新规写死了）

这三要素是第 14 条的核心，过去各地理解不一。**人社部发〔2025〕62 号（2025-11-13 印发）** 首次逐项给出了判断标准：

| 要素        | 官方口径（意见三第一至三项）                                                                                                           |
| --------- | ------------------------------------------------------------------------------------------------------------------------ |
| **工作时间**  | 是否属于法律规定或用人单位要求职工工作的时间。包括但不限于：① 法定工作时间；② 劳动合同约定时间；③ 单位规定时间；④ **完成单位临时指派或特定任务的时间**；⑤ **加班时间**                             |
| **工作场所**  | 是否属于与履行职责相关的区域及所需合理区域。包括但不限于：① 单位能有效管理的区域；② 职工为完成特定工作涉及的**单位以外**相关区域；③ 因工作在**多个工作场所之间往返的合理区域**                           |
| **因工作原因** | 履行职责与所受伤害是否存在因果关系。包括但不限于：① 从事本职生产经营活动；② 完成单位指派工作；③ 维护单位正当利益；④ **工作期间在合理场所内因解决必需的基本生理需要**（喝水、上厕所、休息等），**但不含完全因个人原因造成的伤害** |

**这条有多实用？** 以前争议最大的几种情形，现在有答案了：

| 情形                       | 结论                                | 依据         |
| ------------------------ | --------------------------------- | ---------- |
| 加班时受伤                    | ✅ **算**（加班时间属工作时间）                | 意见三第一项     |
| 领导临时派活时受伤                | ✅ **算**                           | 同上         |
| 在厂区里两个车间之间走路被撞           | ✅ **算**（多个工作场所之间的合理区域）            | 意见三第二项     |
| 去单位外面给客户送货时受伤            | ✅ **算**（单位以外的相关区域）                | 同上         |
| 上班时去茶水间/卫生间摔倒            | ✅ **一般算**（解决必需的基本生理需要）            | 意见三第三项     |
| 上班时因为自己玩手机摔伤             | ❌ **不算**（完全因个人原因）                 | 同上         |
| 居家办公时受伤                  | ✅ **可算**（见下）                      | 意见三第九项     |
| 在家用微信回工作消息时受伤            | ❌ **一般不算**（临时性、偶发性的简单沟通）          | 意见三第九项     |
| **参加单位组织的团建/运动会/培训时受伤**  | ✅ **算**（视为工作原因），但**参加与工作无关的活动除外** | **意见二第四项** |
| **受单位指派去参加别的单位组织的活动时受伤** | ✅ **算**                           | **意见二第四项** |
| **单位组织旅游，自由活动时间自己出去玩受伤** | ❌ **一般不算**（属"与工作无关的活动"）           | 同上（反面）     |
| **长期驻外（有固定住所、有明确作息）时受伤** | ✅ **按"驻在地当地正常工作"处理**，不看是否在信阳      | **意见二第五项** |

> 📌 **"团建算不算"的正确问法**：不是问"是不是单位出钱"，而是&#x95EE;**"这项活动与工作有没有关系、是不是单位组织或指派的"**。
>
> 单位组织、有考勤、有费用报销、有工作内容的拓展训练 → 一般算；纯娱乐性质的旅游，且是自由活动时段自己外出 → 一般不算。
>
> 依据是**人社部发〔2016〕29 号第四项**（不是 2025 年新规，这条 2016 年就有了）。

> ✅ **实证案例（用户亲历，2026-10-19 确认）**：
>
> 本地经办实务中有一例**职工趣味运动会受伤**案，**已按工伤认定成功**。
>
> **意义**：这说明"单位组织的文体活动受伤算工伤"在**信阳的经办实务中是被认可的**，不只是纸面条文——遇到单位说"这是玩，不算工伤"，可以直接说"单位组织的活动视为工作原因，人社部发〔2016〕29 号第四项，我们这儿有先例"。

> **居家办公的完整规则（意见三第九项）**：
>
> - 按单位安排居家办公，**有充分证据证明**因工作原因受伤 → **不应因在家工作而影响认定工伤**
> - 但利用微信、电话、邮件做**简单工作沟通，具有临时性和偶发性**的 → **不视为工作原因**
> - 在家突发疾病是否属"工作时间和工作岗位"，要综合考虑职业要求、岗位职责；有充分证据证明是**按单位要求、与日常强度状态基本一致、明显占用休息时间**的，**可以视为**工作时间和工作岗位

**第二档：视同工伤（第 15 条，3 种）**

| # | 情形                                            | 待遇                    |
| - | --------------------------------------------- | --------------------- |
| 1 | 工作时间 + 工作岗位 + **突发疾病死亡**，或 **48 小时内经抢救无效死亡**  | 按条例享受全部待遇             |
| 2 | 在**抢险救灾**等维护国家利益、公共利益活动中受伤                    | 同上                    |
| 3 | 原在军队服役，因战因公负伤致残，**已取得革命伤残军人证**，到用人单位后**旧伤复发** | **只享受除一次性伤残补助金以外的待遇** |

> 第 1 项是实务中最痛的一条：**48 小时是硬线**，超过即不视同工伤。且必须是"突发疾病"（自身疾病），不是外伤。

**第三档：不得认定（第 16 条，3 种）**

| # | 情形     |
| - | ------ |
| 1 | 故意犯罪   |
| 2 | 醉酒或者吸毒 |
| 3 | 自残或者自杀 |

> 第 16 条是"**排除条款**"：哪怕完全符合第 14、15 条，只要落入这三项，仍不认定。
>
> 注意：**过失犯罪不在此列**；醉酒需有检测证据，不是"喝了酒"。

### 二、实务中的操作顺序（怎么套）

1. **先确认有没有劳动关系**（含事实劳动关系）——没有劳动关系，一般不走工伤，走人身损害赔偿。

   例外：违法发包转包、个人挂靠经营，河南新条例第 25 条允许"无劳动关系也认定工伤"，由具备用工主体资格的单位担责。
2. **再看是不是第 16 条三种排除**——是，直接否；不是，往下走。
3. **再往第 14 条 7 项里套**——套得上 → "应当认定"。
4. **套不上再看第 15 条 3 项**——套得上 → "视同工伤"（注意第 3 项待遇打折）。
5. **都套不上 → 不予认定**，可复议/诉讼。

### 三、最容易吃亏的三个场景

- **"我自己不小心"**：不算排除项。工伤是**无过错责任**，职工本人有过失（非故意）不影响认定。第 16 条只排三种，没有"违章操作"这一项。
- **"单位说给我报销了就不算工伤"**：报销 ≠ 认定。不走认定程序，后续伤残待遇、停工留薪期工资都拿不到。
- **"我下班路上摔了一跤"**：不属第 14 条第 6 项（该项限于交通事故等特定类型），一般不予认定工伤。
