# 劳务派遣工受伤谁负责

| 字段       | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | **法律上由劳务派遣单位（派出你的那家公司）承担工伤保险责任，但真正的用工单位跑不掉——它可以被约定追偿，也可能因过错直接担责。**<br />**① 谁是你的用人单位**：**劳务派遣单位**（签劳动合同、发工资、缴社保的那家）。工伤保险责任**在它身上**。<br />**② 谁给你缴工伤保险**：<br />　• **省内派遣** → **劳务派遣单位**在**本省**参保缴费；<br />　• **跨省派遣到省外** → **必须在用工单位所在地**参保（河南 2022 年起明令禁止省内代缴）。<br />**③ 谁管认定**：参保地人社部门管；**没参保的**，由**事故发生地**人社部门管。<br />**④ 出了事谁掏钱**：参保了 → 基金付大头、派遣单位付单位应负部分；**没参保** → **全部由派遣单位付**。<br />**一句话**：**你告的是派遣公司，但真正指挥你干活的那家，不能一句"不是我员工"就脱身。**             |
| **依据**   | 《工伤保险条例》**第 43 条第 3 款**（借调期间受伤由**原用人单位**承担工伤保险责任，原单位与借调单位可约定补偿办法——**派遣参照此思路**）；**第 62 条第 2 款**（未参保由用人单位按条例标准支付）。<br />**人社部发〔2016〕29 号第七项**（原文见下：参保地规则 + 认定地规则）。<br />《劳务派遣暂行规定》（人社部令第 22 号）——参保与用工比例、岗位限制。<br />**《河南省人力资源和社会保障厅关于进一步规范劳务派遣单位工伤保险有关问题的通知》（2021-12-31 印发，2022-01-01 起施行）**——本省最直接的操作依据，九个要点，见第三节。<br />《劳动合同法》**第 92 条第 2 款**（给被派遣劳动者造成损害的，**劳务派遣单位与用工单位承担连带赔偿责任**）。                                                                  |

| **计算口径** | 项目与标准**同普通工伤**（一次性伤残补助金按本人工资月数、两金按 7,183.3 元/月 × 河南月数，2026 年度文件未发前按上年预核、下发后重核补差）。<br />**参保时**：基金付基金项目，派遣单位付单位项目；**未参保时**：**全部由派遣单位**按条例标准支付（第 62 条第 2 款）。<br />**连带责任**：《劳动合同法》第 92 条第 2 款——给被派遣劳动者造成损害的，**派遣单位与用工单位承担连带赔偿责任**。                                                                                                                                                                                                                      |

## 展开说明

### 一、29 号文第七项原文（三句话，三个规则）

> **七、**&#x7528;人单位注册地与生产经营地不在同一统筹地区的，原则上应在**注册地**为职工参加工伤保险；未在注册地参加工伤保险的职工，可由用人单位在**生产经营地**为其参加工伤保险。  
> **劳务派遣单位跨地区派遣劳动者，应根据《劳务派遣暂行规定》参加工伤保险。建筑施工企业按项目参保的，应在施工项目所在地参加工伤保险。**  
> 职工受到事故伤害或者患职业病后，**在参保地**进行工伤认定、劳动能力鉴定，并按照参保地的规定依法享受工伤保险待遇；**未参加工伤保险的职工，应当在生产经营地**进行工伤认定、劳动能力鉴定，并按照生产经营地的规定**依法由用人单位支付**工伤保险待遇。

**三句话拆开看**：

| # | 规则                                               | 说人话                 |
| - | ------------------------------------------------ | ------------------- |
| 1 | **一般单位**：注册地优先，注册地没参保的可在生产经营地参保                  | 在哪交的社保，就在哪认定、按哪的标准赔 |
| 2 | **派遣**：跨地区派遣按《劳务派遣暂行规定》参保；**建筑企业按项目参保，在施工项目所在地** | 派遣不能"图便宜"在低标准地区交    |
| 3 | **没参保的**：在**生产经营地**（≈事故发生地）认定，**用人单位自己掏钱**       | 没交社保，责任全落派遣单位头上     |

> 🔴 **第 3 句是最容易被忽略、也最致命的一句**：  
> **"未参加工伤保险的，由用人单位支付"**——不是"基金先垫再追"，是**直接由派遣单位付全款**。  
> 很多小派遣公司注册在低费率地区、根本不缴，出了事就是**拿公司全部资产去赔**。

### 二、三家公司，到底谁是谁

劳务派遣里有三个主体，**搞清楚才能找对人**：

| 主体            | 法律身份     | 干的事                | 工伤责任                                                                                                   |
| ------------- | -------- | ------------------ | ------------------------------------------------------------------------------------------------------ |
| **劳务派遣单位**    | **用人单位** | 签劳动合同、发工资、缴社保、派你出去 | **法定承担工伤保险责任**（第一责任）                                                                                   |
| **用工单位**      | 不是用人单位   | 实际指挥你干活、提供工作场所和设备  | **不直接承担工伤责任**，但① 可被派遣单位按协议**追偿**；② **自身有过错**（如没提供安全条件）可能承担**连带赔偿**（劳动合同法第 92 条）；③ 与派遣单位约定**连带**的对职工更有利 |
| **你（被派遣劳动者）** | 职工       | ——                 | 主张权利的一方                                                                                                |

> 📌 **一句话**：**签合同的那家赔你，指挥你干活的那家不能装看不见。**

### 三、河南专项文件九个要点（2021-12-31，2022-01-01 起施行）

这份文件是目前河南最具体的操作口径，摘成一张表：

| 要点                 | 内容                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------- |
| **① 谁算派遣单位**       | 本省注册、有派遣资质的各类企业 + 已备案的**派遣分支机构**                                                      |
| **② 省内派遣**         | 派遣单位**在本省**为被派遣者办工伤保险并缴费                                                              |
| **③ 派到省外**         | **必须在用工单位所在地**参保、按当地标准缴费。**河南自 2022-01-01 起，不得办理向省外派遣的参保登记**                          |
| **④ 假外包真派遣**       | 以**承揽、外包**名义、实际按派遣形式用工的，**按本通知执行**（堵住规避口子）                                            |
| **⑤ 费率怎么定**        | 缴费基数按**被派遣劳动者工资总额**核算；基准费率按**实际用工单位所在行业**的工伤风险类别确定；同时在**两个以上不同风险类别**用工单位的，算**加权平均费率** |
| **⑥ 认定管辖（参保的）**    | 由**参保地**县级以上人社部门办理                                                                    |
| **⑦ 认定管辖（省本级参保的）** | 由**用工单位所在省辖市/直管县**办理                                                                  |
| **⑧ 认定管辖（未参保的）**   | 由**事故发生地**县级以上人社部门办理；有争议由**共同上一级**人社部门**指定管辖**                                        |
| **⑨ 人员变动不申报**      | 人员增减或用工单位变化**未及时申报**，导致经办机构依法不应支付的待遇，**由派遣单位承担**                                      |

> ⚠️ **第 ③ 条的时间点要记牢**：**2022 年 1 月 1 日**起，河南不再给"派到省外的人"在河南参保。  
> 如果现在还有派遣公司在河南给你缴、人却在外省干活 —— **这个参保可能是违规的**，出事容易扯皮。

### 四、出了事，走什么流程（照这个走）

```
第 1 步：确定参保状态
  → 问派遣单位要"工伤保险参保证明"（或自己在"河南人社"APP 查）
  → 已参保 → 记住参保地（决定去哪认定、按哪的标准赔）
  → 未参保 → 记住事故发生地（去那里认定，钱由派遣单位付）

第 2 步：报工伤
  → 由"用人单位"（派遣单位）在 30 日内申报
  → 派遣单位不报 → 你或家属 1 年内自行申报（见 B04_单位不承认工伤怎么办.md）

第 3 步：同时书面通知用工单位
  → 要求其提供事故证明、监控、现场证人、安全管理记录
  → 用工单位不配合 → 留存书面催告记录（后面算过错用）

第 4 步：认定 + 鉴定 + 待遇
  → 参保的：基金付 + 派遣单位付单位应负部分
  → 未参保的：全部由派遣单位付（条例第 62 条）

第 5 步：派遣单位赖账 / 没钱
  → 申请劳动仲裁，把派遣单位列为被申请人
  → 有证据证明用工单位有过错或约定连带的，一并列为共同被申请人
```

### 五、三个最容易踩的坑

**坑 1："我在厂里干活，就该厂里赔"**

**法律上不对。** 你的用人单位是派遣公司，工伤责任首先是它的。  
但——**用工单位不是完全没事**：

- 《劳动合同法》**第 92 条第 2 款**：给被派遣劳动者造成损害的，**派遣单位与用工单位承担连带赔偿责任**；
- 《工伤保险条例》**第 43 条第 3 款**（借调规则）：原用人单位承担工伤保险责任，**但原用人单位与借调单位可以约定补偿办法**；
- 实操中，**把两家一起列为被申请人**往往更容易拿到钱，法院也常判连带。

**坑 2："派遣公司在外地注册，是不是要找外地的部门"**

**看参保地，不看注册地。**（29 号文第七项第三句）

- **已参保** → 去**参保地**认定、按参保地标准赔；
- **未参保** → 去**事故发生地**认定，按事故发生地标准由派遣单位付。

> 💡 **这条对职工的意义**：如果派遣公司偷偷在低标准地区给你参保，你的待遇会按那边的标准算，可能少一截。**参保地是可以查的**，值得一开始就查清。

**坑 3：用工单位说"他不是我们的人，我们不管"**

这句**在工伤责任上成立，在其他方面不成立**：

- **安全生产责任**：《安全生产法》对**实际用工的生产经营单位**同样有要求，出事故要配合调查；
- **事故证明义务**：现场监控、证人、排班记录**都在用工单位手上**，它不提供，认定会很困难；
- **连带责任**：如能证明用工单位**未提供安全条件、强令冒险作业**，可主张连带赔偿。

> 🔴 **实务建议**：事故当天就**书面向用工单位要监控和证人名单**，发微信也算，但要有明确的时间点和诉求。**这是后面主张连带责任的关键证据。**

### 六、给派遣单位 / 用工单位经办人的四句话

1. **别在省外用工却在河南参保**——2022 年起已明令禁止，出事可能被认定参保无效，责任全落自己头上。
2. **人员变动要申报**——不申报导致待遇无法支付，**这笔钱由你承担**（河南专项文件第九点）。
3. **用工单位：给派遣工买一份雇主责任险或意外险**——不是法律强制，但能挡住"连带赔偿"的实际损失。
4. **派遣协议里写清"工伤补偿办法"**——条例第 43 条明确"可以约定补偿办法"。**不约定 ≠ 不用赔，只是赔了以后没人分担。**
