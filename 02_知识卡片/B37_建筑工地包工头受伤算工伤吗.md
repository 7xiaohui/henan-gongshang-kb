# 建筑工地、包工头、层层转包，受伤算工伤吗

| 字段       | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | **算，而且不需要你跟任何一家公司有劳动合同——这是法律专门为工地开的口子。**<br />**核心规则一句话：谁有资质，谁担责。** 包工头个人没资质，他招的人受伤，**由把活发包给他的那个"有用工主体资格"的单位（一般是施工总承包单位或劳务分包公司）承担工伤保险责任**。<br />**三种最常见的情形，对号入座：**<br />**① 包工头个人招你去干活**（最常见）→ 找**把工程包给他的建筑公司**担责（河南条例第 25 条 / 人社部发〔2013〕34 号第七项）。<br />**② 公司把工程违法转包、分包给别的单位** → 找**原发包的那家有资质的公司**担责。<br />**③ 你挂靠在某家公司名下接活** → 找**被挂靠的公司**担责。<br />**一句话：你找不到包工头没关系，往上找一层，那家公司跑不掉。**                                                                                                                                                                                                                                                                                                        |
| **依据**   | ⭐ **条文演进链条（引用时按这个顺序写，别把最早的口径说成最终口径）**：<br />**① 劳社部发〔2005〕12 号第四项（最早来源，"用工主体责任"）**：*建筑施工、矿山企业等用人单位将工程（业务）或经营权发包给不具备用工主体资格的组织或自然人，对该组织或自然人招用的劳动者，由具备用工主体资格的发包方承担**用工主体责任**。*<br />**② 人社部发〔2013〕34 号第七项（升级为"工伤保险责任"）**：*具备用工主体资格的承包单位违反法律、法规规定，将承包业务转包、分包给不具备用工主体资格的组织或者自然人，该组织或者自然人招用的劳动者从事承包业务时因工伤亡的，**由具备用工主体资格的承包单位承担用人单位依法应承担的工伤保险责任**。*<br />**③ 法释〔2014〕9 号第三条第（四）（五）项（法院裁判依据，效力层级最高）**：*（四）用工单位违反法律、法规规定将承包业务**转包**给不具备用工主体资格的组织或者自然人，该组织或者自然人聘用的职工从事承包业务时因工伤亡的，**用工单位为承担工伤保险责任的单位**；（五）个人**挂靠**其他单位对外经营，其聘用的人员因工伤亡的，**被挂靠单位**为承担工伤保险责任的单位。前款第（四）、（五）项明确的单位承担赔偿责任或基金支付待遇后，**有权向相关组织、单位和个人追偿**。*<br />**④ 河南省工伤保险条例（2026-10-01 施行）第 25 条**（本省最直接依据，与 ② 同旨）：*具备用工主体资格的用人单位将承包业务违法转包、分包给不具备用工主体资格的组织或者自然人，该组织或者自然人招用的劳动者从事承包业务时因工伤亡的，**由该具备用工主体资格的用人单位承担工伤保险责任***。<br />**人社部发〔2025〕62 号（意见三）第十项**（无劳动关系也可认定的 3 类情形，与河南条例第 25 条同旨）。<br />**人社部发〔2016〕29 号第七项**（**建筑施工企业按项目参保的，在施工项目所在地参保**；已参保的在参保地认定，未参保的在生产经营地认定）。<br />**人社部发〔2016〕29 号第二项**（超龄人员：未办退休、未领养老金的，原单位承担工伤保险责任；已领养老金的被招用，**已按项目参保的适用《工伤保险条例》**）。<br />⚠️ **为什么必须引法释 9 号第三条**：人社局不认、你要打行政诉讼时，**法院直接看法释〔2014〕9 号第三条**——这是约束法院自身的司法解释，效力层级高于部委文件。<br />⚠️ **为什么也必须引 12 号文第四项**：工地上"违法转包"这个法理的**源头就是 2005 年这一条**，凡单位辩称"这条规则是 2013 年才有的、我那年不适用"的，用 12 号文堵住。<br />《工伤保险条例》（国务院令第 586 号修订）**第 2 条**（适用范围）、**第 62 条第 2 款**（未参保由用人单位按条例标准支付）；《建筑法》**第 28、29 条**（禁止转包、分包限制）。 |
| **适用条件** | **必须同时满足**：<br />① **直接招你的人没有用工主体资格**——典型是**自然人包工头**（个人）、没有营业执照的"施工队"、借用别人资质的队伍；<br />② 你**在他承包的业务范围内**干活受伤（不是自己私下接的活）；<br />③ **往上追的那一层单位有合法资质**（营业执照 / 建筑业企业资质）。<br />**三种情形分清楚**：<br />· **合法分包**（分包给有资质的公司）→ 你和分包公司直接构成关系，由**分包公司**担责，不适用本卡；<br />· **违法转包 / 分包给个人** → 由**原发包的有资质单位**担责；<br />· **挂靠** → 由**被挂靠单位**担责。<br />⚠️ **本卡的"工伤保险责任"≠ 一定构成劳动关系**。法理上是**拟制责任**（把责任压给有资质单位），实务中人社部门可能直接认定工伤，也可能要求先仲裁确认关系，各地口径有差异（见「待核实」）。                                                                                                                                                                                                                                                           |
| **计算口径** | **标准与普通工伤完全一致，一分不少**（这是本卡最重要的结论）：<br />· **已按项目参保** → 待遇从**工伤保险基金**出，按条例标准（一次性伤残补助金按本人工资月数、两项离职补助金按解除时全省社平 × 河南月数）；<br />· **未按项目参保** → **全部由那个有资质的单位按条例标准支付**（条例第 62 条第 2 款），标准不变、只是出钱人变了；<br />· 现行基数 **7,183.3 元/月**（豫社保〔2025〕14 号，核算 2025 年度）；2026 年度按 91,023 元折算为 **7,585.25 元/月**，文件下发后重核补差（见 `A1_口径基准`）。<br />**按项目参保的特别规则**：建筑工地按工程造价一定比例**整体参保**（不按人头核定），**进场工人名单要报**；未报备人员能否享受，各地执行不同（见「待核实」④）。<br />⚠️ **超龄工人在工地**：29 号文第二项第 2 款明文"**已按项目参保等方式**缴纳工伤保险费的，应适用《工伤保险条例》"——所以**超龄不是绝对不算**，关键看项目有没有参保。                                                                                                                                                                                  |
| **易错点**  | ① **以为"我跟包工头干活，没合同，就不能报工伤"**——错。本卡整条就是为这个情形写的。**没劳动合同不影响，甚至不需要你先证明劳动关系。**<br />② **告错对象**：直接去告包工头个人。包工头**没有用工主体资格**，不是适格的用人单位。**要往上追到有资质的公司。**<br />③ **找错"往上那一层"**：工地层层转包（总包 → 专业分包 → 劳务分包 → 包工头），**要追的是"发包给包工头的那一层"**，不一定是总包。**看合同链条，别凭感觉。**<br />④ **把"违法转包"和"合法分包"搞混**——分包给有资质的公司是合法的，此时你和分包公司直接建立关系，不适用第 25 条。<br />⑤ **不知道"按项目参保"这条救命依据**——建筑工地按项目参保是常态，**只要项目参了保，超龄、未签合同、刚进场几天的工人都在保障范围内**。**先查这个项目有没有参保，这一查可能就决定了走哪条路。**<br />⑥ **被"你不是我们公司的人"一句话挡回去**——这句话在法律上不成立（本卡依据栏两条文就是专门否掉它的）。**要书面答复，不要口头。**<br />⑦ **只主张工伤，漏了安全生产责任**——工地事故常伴随单位安全措施缺失，除工伤外还可能涉**民事赔偿**（见 `B27`），但**医疗费等实际支出不能重复拿**。                                                                                         |
| **待核实**  | ① **信阳对"无劳动关系直接认定工伤"的受理口径**——河南条例第 25 条已明确责任，但**窗口是否直接受理，还是要先仲裁确认关系**，各地做法不一，**必须问 7676865**。<br />② **信阳在建项目按项目参保的查询渠道**——能否凭项目名称/工地地址查到参保情况，未确认。<br />③ **"有用工主体资格"的认定标准**——是否只看营业执照，还是要求建筑业企业资质，本地口径未核。<br />④ **未报备进场人员**（未实名登记）能否享受按项目参保待遇——文件未明确，河南实务口径未知。<br />⑤ **层层转包时"责任单位"的确定顺序**（追最近一层还是总包兜底）——法律未细化，需看本地判例。<br />⑥ **包工头自己受伤**（他自己也是干活的）——他既不是"劳动者"也不是"用人单位"，能否适用第 25 条存疑，**本卡不给结论**。<br />⑦ **认定申请主体**：无劳动关系时，**由谁提出申请**（本人 / 有资质单位）、**时限怎么算**，本地未明确。                                                                                                                                                                                                                           |

## 展开说明

### 一、先把"链条"画出来——找责任单位就是顺藤往上摸

```
建设单位（甲方）
    ↓ 总包合同
施工总承包单位  ← 有资质 ✅ 责任候选
    ↓ 专业分包 / 劳务分包
劳务公司        ← 有资质 ✅ 责任候选
    ↓ 违法转包、分包给个人
包工头（张某某）  ← 自然人，无资质 ❌ 不是适格用人单位
    ↓ 招用
你（受伤）
```

**找责任单位的规则：**

| 你被谁招的                 | 责任单位是                               | 依据                     |
| --------------------- | ----------------------------------- | ---------------------- |
| **自然人包工头**            | **把活发包给这个包工头的那家单位**（上图中"劳务公司"或"总包"） | 河南条例第 25 条 / 34 号文第七项  |
| **没执照的"施工队"**         | 同上                                  | 同上                     |
| **挂靠某公司接活**（你用的该公司名义） | **被挂靠的公司**                          | 河南条例第 25 条（"个人挂靠经营"情形） |
| **合法分包的有资质公司**        | 该公司（直接关系，不适用本卡规则）                   | 条例第 2 条                |

> 🔴 **一句话记法**：**往下看是谁招你的，往上看是谁把活给他的。责任在"给他活"的那一层。**

### 二、本卡的"杀手锏"：三句话否掉单位的抗辩

单位最爱说的三句话，以及对应的法条：

| 单位说                      | 法律上的回答                            | 依据                    |
| ------------------------ | --------------------------------- | --------------------- |
| "**你不是我们公司的人，我们没跟你签合同**" | 本条**不以劳动关系为前提**，是法定的责任分配          | 河南条例第 25 条 / 34 号文第七项 |
| "**活是包工头接的，你找他去**"       | 包工头**没有用工主体资格**，责任在他上一层的**有资质单位** | 同上                    |
| "**我们没给你缴工伤保险，没钱赔**"     | **标准不变、主体变更**：未参保就由该单位按条例标准全额支付   | 条例第 62 条第 2 款         |
| "**这个规则是 2013 年才出的，我那年不适用**" | **2005 年就有**：劳社部发〔2005〕12 号第四项已确立"用工主体责任" | **12 号文第四项** → 34 号文第七项 → 法释 9 号第三条 |

> 💡 **谈判时的正确说法**：  
> "按**劳社部发〔2005〕12 号第四项**、**人社部发〔2013〕34 号第七项**、《**河南省工伤保险条例**》第 25 条，承包单位把业务违法分包给不具备用工主体资格的个人，该个人招用的劳动者因工伤亡，**由承包单位承担工伤保险责任**。这跟有没有劳动合同无关。**法院裁判依据是法释〔2014〕9 号第三条第（四）（五）项**。请贵单位在 30 日内依法申报工伤认定。"

### 三、"按项目参保"——工地最该先查的一件事

建筑业有一个特殊制度：**按工程项目整体参加工伤保险**（不是按人头逐个参保）。

| 项目        | 内容                                                                                    |
| --------- | ------------------------------------------------------------------------------------- |
| **谁缴**    | 施工总承包单位（一般按工程造价的一定比例一次性缴纳）                                                            |
| **保谁**    | **项目上所有进场施工人员**，包括未签合同的、刚进场的、超龄的                                                      |
| **依据**    | 人社部发〔2016〕29 号第七项（建筑施工企业按项目参保的，**在施工项目所在地参保**）                                        |
| **好处**    | 一旦参保，**超龄工人、没合同的工人、包工头带来的人，都在保障范围内**（29 号文第二项第 2 款："已按项目参保等方式为其缴纳工伤保险费的，应适用《工伤保险条例》"） |
| **要做的动作** | **出事后第一件事就去查这个项目参没参保**——查到了，路就好走；没查到，就走"单位全额支付"那条                                     |

> 🔴 **这是全卡信息价值最高的一条**。很多工地受伤的工人不知道有这个制度，直接放弃了。  
> **问法**："请问 ×× 项目（工地地址 ××）有没有按项目参加工伤保险？"——问当地社保经办机构，或让单位出具参保凭证。

### 四、四种常见情形，照着对人

| 场景                                                  | 结论               | 走哪条路                                             |
| --------------------------------------------------- | ---------------- | ------------------------------------------------ |
| **A. 老王经老乡介绍，跟着张包工头在某楼盘工地扎钢筋，摔伤。张包工头是个人，从某劳务公司接的活** | ✅ **是工伤**        | 由**该劳务公司**承担工伤保险责任（河南条例第 25 条）；查该项目是否按项目参保       |
| **B. 老李在某建筑公司自有施工队干活，签了劳动合同**                       | ✅ **是工伤**        | 普通工伤路径，公司就是用人单位                                  |
| **C. 老赵 65 岁，在某工地看材料，项目已按项目参保**                     | ✅ **适用《工伤保险条例》** | 29 号文第二项第 2 款（"已按项目参保等方式"）——**超龄不影响**            |
| **D. 老孙 68 岁，在私人自建房工地干活（业主自己找人），业主是个人**             | ⚠️ **走不通工伤**     | 业主是自然人，**没有"有用工主体资格的单位"可追**；只能走**民事赔偿**（民法典侵权责任） |

> 💡 **场景 D 是关键边界**：本卡的前提是"**往上能追到一个有资质的单位**"。追不到（纯私人建房、农村自建），就只能走民事。

### 五、材料准备：比普通工伤多两样

除 `B06` 列的常规材料外，工地案子**必须多准备**：

| # | 材料                | 从哪来                                          | 为什么关键              |
| - | ----------------- | -------------------------------------------- | ------------------ |
| 1 | **证明"谁把活包给谁"的链条** | 施工现场公示牌（五牌一图）、合同照片、项目部人员名单、微信工作群             | 这是确定责任单位的唯一依据      |
| 2 | **证明你在这个工地干活的证据** | 门禁记录、考勤、工资转账（包工头微信转账也算）、工作服/安全帽、班组群聊天记录、宿舍照片 | 替代劳动合同，证明"我确实在这干活" |
| 3 | 项目参保凭证（如已参保）      | 社保经办机构查询 / 单位出具                              | 决定走基金还是走单位         |

> 💡 **最容易被忽略的第 1 项**：**工地大门口的"五牌一图"（工程概况牌、管理人员名单及监督电话牌等）当天就要拍下来**——上面写着**建设单位、施工单位、项目经理、监督电话**。这是找责任单位最快的一条线索，而它**在工程结束后就拆了**。

### 六、跟"现场取证"怎么配合

工地案子的取证有个特殊点：**现场会被迅速清理**（工地赶工期的特性）。
