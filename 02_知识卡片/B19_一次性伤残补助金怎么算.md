# 一次性伤残补助金怎么算

| 字段 | 内容 |
|---|---|
| **结论** | **一次性伤残补助金 = 本人工资 × 对应月数**。<br>月数按伤残等级**全国统一**：一 27 / 二 25 / 三 23 / 四 21 / 五 18 / 六 16 / 七 13 / 八 11 / 九 9 / **十 7**。<br>**由工伤保险基金支付**，只要鉴定了伤残等级就有，**不管是否解除劳动关系**（这是它和另外两项补助金最大的区别）。 |
| **依据** | 《工伤保险条例》**第 35 条**（一至四级）、**第 36 条**（五六级）、**第 37 条**（七至十级）、**第 64 条**（本人工资定义）。<br>《河南省工伤保险条例》（2026）第 35、36、37 条（沿用国务院月数，未改）。 |
| **适用条件** | ① 已取得《认定工伤决定书》；<br>② 已作出劳动能力鉴定结论（**有伤残等级**，一般 1–10 级）；<br>③ 未达到伤残等级（无等级）的，**没有**这一项。 |
| **计算口径** | **本人工资** = 受伤 / 确诊职业病前 **12 个月平均月缴费工资**。<br>· 高于**全省**职工平均工资 **300%** → 按 300% 封顶；<br>· 低于 **60%** → 按 60% 保底。<br>**注意**：河南已省级统筹，封顶保底一律用**全省**社平，**不是**信阳的统筹地区社平。依据：豫人社〔2018〕44 号 二（三）。 |
| **易错点** | ① **"本人工资"≠ 实发到手工资，也 ≠ 应发工资。** 法律口径是**月缴费工资**（社保缴费基数）。单位按最低基数缴费的，算出来的钱会比实际工资低——**差额可以主张单位补**（河南条例第 46 条）。<br>② **把封顶基数用错**：本人工资的 300%/60% 在河南用**全省**社平，不是信阳统筹地区社平。很多人照抄国家条例第 64 条原文"统筹地区"就错了。<br>③ **奖金、加班费口径**：缴费工资一般不含加班费，但含经常性奖金、津贴，具体看当地申报口径——这部分最容易和单位扯皮。<br>④ **以为解除劳动关系才有**：错。**不解除也有**，一至四级甚至必须保留劳动关系。 |
| **待核实** | ① **本人工资上下限**：**现行基数 7,183.3 元/月**（豫社保〔2025〕14 号）→ 下限 **4,309.98 元**、上限 **21,549.9 元**。**2026 年度计发文件截至 2026-10-19 仍未发布**（2025 年"在岗职工"年均未公布）；按 91,023 元折算的 7,585.25 元（对应下限 4,551.15 / 上限 22,755.75）**几乎可确定就是 2026 年度基数**，只差省社保中心发文。详见 `../01_规则前置/A1_口径基准.md` 第二节。<br>② 单位未足额缴费导致待遇降低的，主张差额的实操路径（仲裁 vs 社保稽核），信阳口径需确认。 |
| **出处链接** | 《工伤保险条例》第 35–37、64 条：https://www.mohrss.gov.cn/wap/zc/fgwj/202011/t20201103_394950.html<br>《河南省工伤保险条例》（2026）：https://law.pkulaw.com/chinalaw/acfc133878ed991f28edee68a8cbbe6dbdfb.html |

## 展开说明

### 一、月数总表（背下来最省事）

| 等级 | 月数 | 支付方 | 是否需解除劳动关系 |
|---|---|---|---|
| 一级 | 27 | 工伤保险基金 | 否（且应保留劳动关系、退出岗位） |
| 二级 | 25 | 基金 | 否 |
| 三级 | 23 | 基金 | 否 |
| 四级 | 21 | 基金 | 否 |
| 五级 | 18 | 基金 | 否（解除时另有两项补助金） |
| 六级 | 16 | 基金 | 否 |
| 七级 | 13 | 基金 | 否 |
| 八级 | 11 | 基金 | 否 |
| 九级 | 9 | 基金 | 否 |
| 十级 | **7** | 基金 | 否 |

> 一句话：**"一次性伤残补助金"是伤残待遇的"入场券"，和走不走人无关。**
> "一次性工伤医疗补助金 + 一次性伤残就业补助金"才是"走人才有"的（且只限五至十级）。

### 二、计算示例（十级，本人工资不同情形）

假设本人工资申报为 **5,000 元/月**，鉴定为十级：

```
5,000 × 7 = 35,000 元
```

假设本人工资申报为 **3,000 元/月**（低于下限 4,309.98）：

```
按下限 4,309.98 × 7 = 30,169.86 元   ← 保底机制在起作用
```

假设本人工资为 **25,000 元/月**（高于上限 21,549.9）：

```
按上限 21,549.9 × 7 = 150,849.3 元   ← 封顶机制在起作用
```

> ⚠️ **封顶保底跟着"计发基数"走**：现行基数 7,183.3 元/月（豫社保〔2025〕14 号）
> → 下限 = 7,183.3 × 60% = **4,309.98**；上限 = 7,183.3 × 300% = **21,549.9**。
> 若按统计局 2025 年就业人员年均 91,023 元折算的 **7,585.25 元**试算（**2026 年度基数几乎可确定即为此数，只差省社保中心一纸文件；文件下发后重核补发差额**）→ 下限 4,551.15 / 上限 22,755.75。
> **写进材料前必须核对当年计发文件**——上下限每年跟着变。

### 三、和另外两笔钱的关系（最容易混）

| 项目 | 支付方 | 触发条件 | 基数 | 等级范围 |
|---|---|---|---|---|
| **一次性伤残补助金** | 工伤保险基金 | **鉴定有等级即可** | 本人工资 | 1–10 级 |
| 一次性工伤医疗补助金 | 工伤保险基金 | **解除/终止劳动关系** | 全省上年度职工月平均工资 | **5–10 级** |
| 一次性伤残就业补助金 | **用人单位** | **解除/终止劳动关系** | 全省上年度职工月平均工资 | **5–10 级** |
| 伤残津贴（按月） | 1–4 级基金 / 5–6 级单位 | 有等级 | 本人工资 × 比例 | 1–6 级 |

> 详细月数和缴费方见：`B20_一次性工伤医疗补助金和就业补助金有什么区别.md`

### 四、单位按最低基数缴费，怎么办

这是河南（乃至全国）中小企业最普遍的问题：你实际工资 6,000，单位按 3,500 申报缴费。

- 结果：一次性伤残补助金按 3,500 算，少了一大截。
- 依据：**《河南省工伤保险条例》（2026）第 46 条**："因用人单位缴纳工伤保险费基数不实造成工伤职工工伤保险待遇降低的，由用人单位承担责任，并支付差额。"
- 做法：留好工资流水、个税记录、工资条，主张差额；也可向社保稽核部门举报单位少缴。

### 五、什么时候能拿到

- 河南新条例第 43 条：**一次性伤残补助金自申领之日起次月内支付**。
- 前提：先有《认定工伤决定书》+ 劳动能力鉴定结论（河南条例第 44 条：凭这两份材料享受待遇）。
