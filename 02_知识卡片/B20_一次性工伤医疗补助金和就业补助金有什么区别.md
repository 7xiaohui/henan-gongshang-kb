# 一次性工伤医疗补助金和就业补助金有什么区别

| 字段       | 内容                                                                                                                                                                                                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **结论**   | 两笔钱都**只在五至十级伤残 + 解除/终止劳动关系时**才有，但**出钱的人不同**：<br />· **一次性工伤医疗补助金 → 工伤保险基金出**（管你以后看病）<br />· **一次性伤残就业补助金 → 用人单位出**（管你以后找工作难）<br />**基数都是"全省上年度职工月平均工资"**（2026-10-01 起由"统筹地区"改为"全省"）。<br />**河南月数**：医疗补助金 五16 / 六14 / 七12 / 八10 / 九8 / **十6**；就业补助金 五56 / 六46 / 七36 / 八26 / 九16 / **十6**。                                                                    |
| **依据**   | 《工伤保险条例》**第 36 条**（五六级）、**第 37 条**（七至十级）。<br />《河南省工伤保险条例》（2026）**第 36、37 条**（月数、基数）、**第 38 条**（职业病增发 30%、退休递减规则）。                                                                                                                                                                                                                                          |
| **适用条件** | 三个条件缺一不可：<br />① 伤残等级在 **5–10 级**（一至四级**没有**这两项）；<br />② **劳动关系解除或终止**（七至十级限于"合同期满终止"或"职工本人提出解除"；五六级限于"职工本人提出解除或终止"）；<br />③ 未达到法定退休年龄、未办理退休手续（**已达退休年龄或已办退休的，两项都不支付**——第 38 条）。                                                                                                                                                                            |
| **计算口径** | **金额 = 全省上年度职工月平均工资 × 对应月数**<br />· 基数时点：**解除或终止劳动关系时**的全省上年度职工月平均工资；<br />· 基数范围：**全省**（2026-10-01 起），旧口径为"统筹地区"；<br />· 职业病：**一次性工伤医疗补助金**增发 **30%**（就业补助金不增发）。                                                                                                                                                                                           |
| **易错点**  | ① **两笔钱的责任主体搞反**——很多人以为两笔都是基金给。**就业补助金是单位掏的**，单位不给就是欠薪性质，可以仲裁。<br />② **以为自动就有**——不解除劳动关系就不发，一直留着不算欠。但**合同期满终止**也会触发，不需要职工提。<br />③ **忘记退休递减规则**：距法定退休年龄不足 5 年的，**就业补助金**每少 1 年递减 20%，不足 1 年按 10% 支付；**已达退休年龄的，两项都不给**。这条最容易被单位拿来压价。<br />④ **基数记成"本人工资"**——错，这两项用社平工资，不用本人工资。<br />⑤ **职业病只增发医疗补助金**，不是两笔都增发。                                              |
| **待核实**  | ① **基数年度**：**7,183.3 元/月是现行有效基数**（豫社保〔2025〕14 号，核算 2025 年度，已核原件）；**2026 年度计发文件截至 2026-10-19 未发布**，按 91,023 元折算的 **7,585.25 元**（**几乎可确定就是 2026 年度基数**，只差发文）→ 见 `../01_规则前置/A1_口径基准.md`。<br />② **领完两项后，后续工伤医疗费还能不能报？** 新条例第 38 条**未再规定**"工伤保险关系同时终止"（旧条例第 27 条曾明写）。领完两项后是否仍保留工伤医疗待遇，**须向窗口确认**——这一条直接影响"拿了钱以后旧伤复发怎么办"。<br />③ 五六级"解除或终止"是否必须由职工本人提出，各地理解略有差异。 |

## 展开说明

### 一、两张表看清差别

| 维度      | 一次性工伤医疗补助金             | 一次性伤残就业补助金                  |
| ------- | ---------------------- | --------------------------- |
| **谁出钱** | 工伤保险基金                 | **用人单位**                    |
| 立法目的    | 补偿你离职后还要继续看工伤的费用       | 补偿你因伤残导致的再就业困难              |
| 支付前提    | 解除/终止劳动关系              | 同左                          |
| 等级范围    | 5–10 级                 | 5–10 级                      |
| 基数      | 全省上年度职工月平均工资           | 同左                          |
| 职业病增发   | **增发 30%**             | 不增发                         |
| 退休递减    | 无                      | **有**（不足 5 年递减，不足 1 年按 10%） |
| 未参保单位   | 由单位承担（单位没缴费就没有"基金"这回事） | 由单位承担                       |

### 二、河南月数对照表（背这张就够）

| 等级 | 医疗补助金（基金） | 就业补助金（单位） | 合计     |
| -- | --------- | --------- | ------ |
| 五级 | 16        | 56        | **72** |
| 六级 | 14        | 46        | **60** |
| 七级 | 12        | 36        | **48** |
| 八级 | 10        | 26        | **36** |
| 九级 | 8         | 16        | **24** |
| 十级 | **6**     | **6**     | **12** |

> **记忆点**：五至九级，就业补助金是医疗补助金的 3 倍以上（五级 56÷16≈3.5）；到十级突然变成 1:1（各 6 个月）。**十级是最"均等"的一档。**

### 三、算例（按 **7,183.3** 元/月基数，现行有效口径，仅示范算法）

**十级，解除劳动关系：**

```
医疗补助金 = 7,183.3 × 6  = 43,099.8 元   （基金付）
就业补助金 = 7,183.3 × 6  = 43,099.8 元   （单位付）
合计       = 86,199.6 元
```

**八级，距法定退休年龄还有 3 年（递减）：**

```
医疗补助金 = 7,183.3 × 10 = 71,833.0 元   （不递减）
就业补助金基数 = 7,183.3 × 26 = 186,765.8 元
  距退休不足 5 年，少 3 年 → 每少 1 年递减 20% → 递减 60%
  实付 = 186,765.8 × 40% = 74,706.32 元
合计 ≈ 146,539.32 元
```

> ⚠️ 这里的递减算法是"距退休不足 5 年，**每减少一年递减 20%**"。上面按"3 年 → 递减 60% → 支付 40%"演算，属常见理解，**但递减是"逐年递减"还是"按档次递减"，窗口口径可能不同**，涉及临界年份（如刚好差 1 年、差 4 年 11 个月）务必现场确认。

**职业病（十级）增发 30%：**

```
医疗补助金 = 7,183.3 × 6 × 1.3 = 56,029.74 元
就业补助金 = 7,183.3 × 6       = 43,099.8 元  ← 不增发
```

> 🔴 **基数只能用官方文件里的数**：本卡按 **7,183.3 元/月**，出处 **豫社保〔2025〕14 号**（核算 2025 年度，已核到原件）。
>   
> **2026 年度计发文件截至 2026-10-19 仍未发布**——因为 2025 年"在岗职工"年平均工资省统计局还没公布。
>   
> 若按统计局 2025 年"就业人员"年均 91,023 元折算的 **7,585.25 元**试算（**2026 年度基数几乎可确定即为此数，文件下发后重核补差**）：十级合计 91,023 元；八级合计约 154,739 元；十级职业病医疗补助金 59,165 元。
>   
> **基数是"解除或终止劳动关系那一年"公布的上年度社平，不是受伤那一年。** 详见 `../01_规则前置/A1_口径基准.md` 第二、三节。

### 四、为什么这两笔钱最容易和单位打架

1. **就业补助金是单位自掏腰包**，金额又大（五级 56 个月，按 7,183 元算就是 40 万+），单位有强动力拖、谈、压。
2. 单位常用话术：
   - "你先签个自愿放弃，我给你多缴几个月社保" → **放弃这两项后再想主张很难**。
   - "你都差两年退休了，按 10% 给你" → 只有**不足 1 年**才是 10%，差两年应该是递减后的比例，别被套。
   - "这两笔是二选一" → **错，是两笔，两个主体**。
3. 一旦签了"一次性了结"协议，**再翻案难度极大**（参见 `B28_工伤私了协议有效吗.md`）。

### 五、一句话区分

> **医疗补助金 = 基金给你以后看病的钱；就业补助金 = 单位给你以后找工作的钱。**
>   
> **一个不用求单位，一个必须求单位。**
