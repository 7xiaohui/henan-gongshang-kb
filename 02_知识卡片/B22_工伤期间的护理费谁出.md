# 工伤期间的护理费谁出

| 字段 | 内容 |
|---|---|
| **结论** | **护理费分两段、两个出钱人，这是本卡最核心的一句话：**<br>**① 停工留薪期内**（还没评残、还在治疗康复）——**由用人单位负责**（《工伤保险条例》**第 33 条第 3 款**：*"生活不能自理的工伤职工在停工留薪期需要护理的，由所在单位负责。"*）。**单位不派人 → 你家属/雇人护理的合理费用由单位承担。**<br>**② 评定伤残等级后**，经**劳动能力鉴定委员会确认需要生活护理的**——**由工伤保险基金按月支付生活护理费**（条例第 34 条 / 河南条例第 34 条），标准为**鉴定结论作出时**全省社平（河南现行 7,183.3 元/月）的 **50% / 40% / 30%**。<br>**两个关键提醒**：① **护理费不会自动给**，必须**申请生活自理障碍等级鉴定**并获"需要生活护理"确认；② **两段不能重复拿**——评残后进入基金按月支付阶段，停工留薪期那段的钱要单独向**单位**主张。 |
| **依据** | 《工伤保险条例》**第 33 条第 3 款**（停工留薪期内护理**由所在单位负责**）、**第 34 条**（评残后经确认需生活护理的，基金按月付；标准为**统筹地区**上年度职工月平均工资 50%/40%/30%）。<br>《河南省工伤保险条例》（2026）**第 34 条**：*"工伤职工已经评定伤残等级并经劳动能力鉴定委员会确认需要生活护理的，从工伤保险基金按月支付生活护理费。生活护理费按照生活完全不能自理、生活大部分不能自理、生活部分不能自理三个不同等级支付，其标准分别为**劳动能力鉴定结论作出时全省上年度职工月平均工资**的百分之五十、百分之四十、百分之三十。"*<br>《河南省工伤保险条例》**第 57 条**（全省社平口径）。<br>《河南省劳动能力鉴定委员会关于下放劳动能力鉴定事项及加强属地化管理的通知》（2026-01-01 起）：**生活自理障碍程度等级鉴定由各地市劳动能力鉴定委员会负责**。 |
| **适用条件** | **停工留薪期段**：① 已被认定工伤（或正在认定中，费用先行垫付）；② 在停工留薪期内；③ **生活不能自理，确需护理**。<br>**基金段**：① **已评定伤残等级**；② **经劳动能力鉴定委员会确认"需要生活护理"**；③ 达到三档之一（完全 / 大部分 / 部分）。<br>⚠️ **注意：伤残等级和护理等级是两套鉴定**。评了八级伤残不等于有护理费；反过来，护理等级也不必然与伤残等级对应。 |
| **计算口径** | **基金按月护理费 = 全省社平 × 比例**<br>· **生活完全不能自理 → 50%**<br>· **生活大部分不能自理 → 40%**<br>· **生活部分不能自理 → 30%**<br>· 基数时点 = **劳动能力鉴定结论作出时**的全省上年度职工月平均工资（河南条例第 34 条原文，**不是受伤时、也不是解除关系时**）。<br>**按现行基数 7,183.3 元/月测算（月标准）**：<br>· 完全不能自理 **3,591.65 元/月**（年约 4.31 万）<br>· 大部分不能自理 **2,873.32 元/月**（年约 3.45 万）<br>· 部分不能自理 **2,154.99 元/月**（年约 2.59 万）<br>**停工留薪期段**：法律未定统一标准，实务按**实际发生的合理护理费用**（家属误工损失、护工市场价）主张，**由单位承担**。 |
| **易错点** | ① **以为评了伤残就自动有护理费**——错。**必须经劳鉴委确认"需要生活护理"**，且要在鉴定申请里一并提出（详见 `B14_生活自理障碍等级是什么.md`）。<br>② **把两段混成一段**——停工留薪期的护理是**单位**的责任，评残后才是**基金**按月付。**很多人只拿到了基金那笔，漏了单位那段。**<br>③ **以为护理费按"本人工资"算**——错，按**全省社平**，与本人工资无关。<br>④ **以为基数是受伤那年**——错，是**鉴定结论作出时**的全省社平。<br>⑤ **家属护理不好意思要钱**——**家属护理是法律上承认的护理方式**，可以主张误工损失/护理费，别默认"自己人照顾就白干"。<br>⑥ **生活不能自理但没做护理等级鉴定**——出院就直接回家养，几年后想要护理费，**举证极难**。伤情稳定时就把鉴定做了。 |
| **待核实** | ① 信阳本地**停工留薪期护理费**的支付标准（是否有参照当地护工市场价的指导口径）——窗口/仲裁确认。<br>② 河南是否有"护理费随待遇调整同步增加"的年度文件（见 `../03_权威资料/C3_调整2025年伤残津贴等待遇.pdf`，需逐年核对）。<br>③ 信阳劳鉴委办理**生活自理障碍等级鉴定**的具体批次与材料要求（是否与伤残鉴定一并申请）。 |

## 展开说明

### 一、两段护理费对照表（**这张表是本卡的全部要点**）

| | **第一段：停工留薪期内** | **第二段：评定伤残等级后** |
|---|---|---|
| **时间** | 受伤 → 评残结论作出 | 评残结论作出 → 终身（或至不再需要护理） |
| **谁出钱** | **用人单位** | **工伤保险基金**（未参保的由单位） |
| **依据** | 条例第 33 条第 3 款 | 条例第 34 条 / 河南条例第 34 条 |
| **前提** | 生活不能自理、需要护理 | 已评残 **+** 经劳鉴委**确认需要生活护理** |
| **标准** | 法律未定统一数，按**实际合理护理费用**主张 | **全省社平 × 50% / 40% / 30%** |
| **发法** | 一次性或按实际支出结算（与单位协商/仲裁） | **按月支付，长期** |
| **要不要鉴定** | 不需要（凭病历证明生活不能自理） | **必须做生活自理障碍等级鉴定** |

> 🔴 **一句话记牢**：**"治疗期间单位管，评残之后基金管。"**
> 这条分界线在**《工伤保险条例》第 33 条第 3 款**和**第 34 条**之间——**同一部条例，相邻两条，出钱人完全不同。**

### 二、第一段（停工留薪期）：单位负责，但法律没给标准数

#### 2.1 条文原文

> 《工伤保险条例》**第 33 条第 3 款**：
> "**生活不能自理的工伤职工在停工留薪期需要护理的，由所在单位负责。**"

**注意"负责"两个字**：法律没说"支付护理费 XX 元/月"，只说"由所在单位**负责**"。这留出了三种履行方式：

| 方式 | 说明 |
|---|---|
| **① 单位派人护理** | 单位安排护工或员工照顾 |
| **② 单位支付护理费** | 你自己请人，单位出钱 |
| **③ 家属护理 + 单位承担费用** | 家属护理视为一种护理劳动，**单位应承担相应费用**（通常按当地护工市场价或家属误工损失计算） |

#### 2.2 实务上怎么主张

- **留证据**：住院期间的护理记录、医嘱"需陪护"、护工发票/收据、家属请假证明和工资损失证明。
- **别接受"你自己家人照顾，还要什么钱"**——家属护理是法定认可的护理方式，**不等于免费**。
- **金额参考**：多数地区按**当地护工日工资 × 护理天数**，或按**上年度居民服务等行业平均工资**计算。信阳具体口径需向窗口/仲裁确认。

### 三、第二段（评残后）：基金按月付，三档定终身

#### 3.1 三档标准（现行基数下的月金额）

| 护理等级 | 比例 | 月金额（按 7,183.3 元/月） | 年金额 |
|---|---|---|---|
| **生活完全不能自理** | **50%** | **3,591.65 元** | 约 4.31 万元 |
| **生活大部分不能自理** | **40%** | **2,873.32 元** | 约 3.45 万元 |
| **生活部分不能自理** | **30%** | **2,154.99 元** | 约 2.59 万元 |

> ⚠️ **基数说明**：以上按现行有效基数 **7,183.3 元/月**（豫社保〔2025〕14 号，核算 2025 年度）测算。
> **2026 年度计发文件截至 2026-10-19 尚未发布**（因 2025 年"在岗职工"年平均工资未公布）；按 91,023 元折算的 **7,585.25 元**——**2026 年度基数几乎可确定即为此数**，只差省社保中心发文；下发后重核补差。
> 正式核定以当年计发文件为准；文件出台前按上年基数预核，下发后**重核补发差额**。详见 `../01_规则前置/A1_口径基准.md` 第二节。

#### 3.2 基数时点：**鉴定结论作出时**，不是受伤时

河南条例第 34 条原文：*"其标准分别为**劳动能力鉴定结论作出时**全省上年度职工月平均工资的百分之五十、百分之四十、百分之三十。"*

| 你的情况 | 基数用哪年 |
|---|---|
| 2024 年受伤，2025 年评残 | 用 **2025 年**公布的基数（即 7,183.3，核算 2025 年度） |
| 2025 年受伤，2027 年才评残 | 用 **2027 年**的基数（届时按新文件） |

> 💡 **和两项补助金的区别**：两项补助金用"**解除/终止劳动关系时**"的基数（河南条例第 36、37 条），护理费用"**鉴定结论作出时**"的基数（第 34 条）。**三个时点别记混。**

#### 3.3 护理费会调整吗

- **会**。河南每年有《调整伤残津贴等工伤保险待遇》的文件（如 2025-09-30 那份），护理费随待遇一并上调。
- **上调是制度化动作，不用你每年申请**——但**发现没调，要主动问**。

### 四、护理等级怎么定（详见另一张卡）

判断"能不能自理"看**五项**：

| # | 项目 |
|---|---|
| 1 | **进食** |
| 2 | **翻身** |
| 3 | **大、小便** |
| 4 | **穿衣、洗漱** |
| 5 | **自主行动** |

- **五项都不能自理** → 生活**完全**不能自理（50%）
- **三至四项不能自理** → 生活**大部分**不能自理（40%）
- **一至二项不能自理** → 生活**部分**不能自理（30%）
- **五项都能自理** → 无护理依赖，**不发护理费**

> 具体判定由劳动能力鉴定委员会依据 GB/T 16180—2014 作出。详见 `B14_生活自理障碍等级是什么.md`。

### 五、五个高频问题

**Q1：我自己家人照顾我，能要护理费吗？**
A：**能。** 家属护理是法定认可的护理方式。停工留薪期段由**单位**承担（按护工市场价或家属误工损失）；评残后经鉴定需护理的，由**基金**按月付。

**Q2：护理费和伤残津贴能一起拿吗？**
A：**能，这是两笔不同的钱。** 伤残津贴是补"劳动能力丧失导致的收入损失"（一至四级基金付、五六级单位付），护理费是补"生活不能自理需要人照顾"的支出。**同时符合条件就同时拿。**

**Q3：评残时说"生活能自理"，后来恶化了怎么办？**
A：可申请**复查鉴定**。生活自理障碍程度变化，护理费相应调整（人社部发〔2025〕62 号也明确：复查鉴定结论变化时，伤残津贴、护理费按新结论调整）。

**Q4：单位没参保，护理费谁付？**
A：**全部由单位付**（河南条例第 33 条第 1 款：未依法参加工伤保险的，工伤保险待遇由用人单位支付）。单位不付的，可申请**工伤保险基金先行支付**（《社会保险基金先行支付暂行办法》人社部令第 15 号），基金支付后向单位追偿。见 `B26_单位没交工伤保险谁来赔.md`。

**Q5：护理费要交税吗？**
A：工伤保险待遇**不征个人所得税**（属法定社会保险待遇）。这是常识性判断，具体以税务口径为准，本卡不作税务意见。

### 六、一页速查

```
【两段，两个出钱人】
停工留薪期内（未评残）→ 单位负责（条例第33条第3款）
评残后（经确认需护理）→ 基金按月付（条例第34条）

【基金段三档（按全省社平）】
完全不能自理 50%  → 现行 3,591.65 元/月
大部分不能自理 40% → 现行 2,873.32 元/月
部分不能自理 30%  → 现行 2,154.99 元/月
基数时点 = 劳动能力鉴定结论作出时

【五项判断自理能力】
进食 / 翻身 / 大小便 / 穿衣洗漱 / 自主行动
5项不能 → 完全 | 3-4项 → 大部分 | 1-2项 → 部分 | 全都能 → 无

【三件必须做的事】
□ 评残时"一并"申请生活自理障碍等级鉴定（不申请就不给）
□ 停工留薪期段的护理费用单独向单位主张（别只盯基金那笔）
□ 家属护理留证据：医嘱需陪护、护理记录、误工证明

【千万别做】
✗ 以为评了伤残就自动有护理费
✗ 以为护理费按本人工资算（按全省社平）
✗ 出院就散、不做鉴定，几年后再想要
```
