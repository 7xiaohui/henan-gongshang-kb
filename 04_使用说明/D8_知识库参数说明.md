# 知识库参数说明（Embedding / Rerank / Top K / 温度）

> **这份文件解决一个问题**：Cherry Studio 设置页里那几个英文参数，到底该填什么、为什么这么填。  
> 照着填就行，不用理解原理。想理解的话，**第四节**用大白话解释了。

**适用版本**：Cherry Studio（2025 年以后版本）　｜　**写于**：2026-10-20

---

## 一、直接照着填（最省事）

| 参数                  | 填什么                    | 说明                             |
| ------------------- | ---------------------- | ------------------------------ |
| **Embedding 模型**    | **`bge-m3`**（默认那个，不要换） | 中文场景够用。**换了要重新向量化整个库**，且必须与库一致 |
| **Rerank**          | **先关闭**                | 41 份的库，不开也够准。跑完测试再决定要不要开       |
| **Top K**           | **8**                  | 先用 8，跑完 14 道题看有没有漏，再往下调到 5 或 6 |
| **温度（Temperature）** | **0.2**                | 法规类问答，越低越稳。范围 0.1–0.3，别超过 0.5  |
| **最大上下文数（如有）**      | 保持默认                   | 不用动                            |

**一句话**：`bge-m3` + Rerank 关 + Top K 8 + 温度 0.2。

---

## 二、这几个参数分别在管什么

提问到回答之间，其实走了两步，**参数分属两步，不能混着理解**。

**第一步：找材料（检索）**

```
你的提问
  ↓
Embedding —— 把文字变成一串数字坐标
  ↓
在知识库里比坐标，找出最像的 K 段  ← Top K 在这里
  ↓
Rerank —— 把这 K 段再排一次序，砍掉不相干的
  ↓
这几段材料送给模型
```

**第二步：写答案（生成）**

```
模型读「你的问题 + 刚才那几段材料」
  ↓
一个词一个词往外写   ← 温度在这里
  ↓
回答
```

**关键区别**：

- **Embedding / Top K / Rerank 决定"模型看到什么材料"**
- **温度决定"模型怎么写"**

材料没找对，温度再低也答不对。**先调前三个，再说温度。**

---

## 三、逐个说清楚

### 3.1 Embedding（向量模型）

**它干什么**：把一段中文变成一串数字（比如 1024 个小数）。意思相近的两句话，算出来的数字串也相近。

**为什么要它**：计算机不会比"意思像不像"，只会比"数字差多少"。转成数字才能算。

**你要注意的三件事**：

1. **知识库和提问必须用同一个 Embedding 模型**。这是硬要求——用 A 模型转的库，用 B 模型提问，两套数字不在一个坐标系里，**检索会直接失效**（不是变差，是基本找不到）。
2. **换模型 = 整个库要重新向量化**。Cherry Studio 会自动重做，但 41 份文件也要等几分钟。
3. **中文用 `bge-m3` 就够**。它是智源研究院的中文向量模型，在中文语义匹配上表现好，且支持长文本。**没必要换更大更贵的。**

> ⚠️ **最常见的坑**：看到某篇文章推荐别的 Embedding 模型，换掉之后忘了重新向量化 → 检索全乱 → 以为"知识库没用"。

### 3.2 Top K（取几段）

**它干什么**：每次提问，从库里挑出**最像的 K 段**材料送给模型。

**注意是"段"不是"份"**。一份知识卡会被切成好几段（按九字段切），所以 K=8 可能只覆盖两张卡。

**K 太小会怎样**：漏材料。问"工亡能赔多少"，同时需要 B38（三项待遇）+ A1 第 39 条 + 计发基数，K=3 可能只取到两段卡内容，**漏掉丧葬费或抚恤金**。

**K 太大会怎样**：噪音。无关片段混进来，模型可能被带偏，而且**费 token、慢**。

**怎么定**：

- 先设 **8**，跑完 D2 那 14 道题
- 如果有题答漏了关键点 → 调到 10 或 12
- 如果答得又全又稳 → 试着降到 6，看是否还稳（更省更快）
- **41 份的库，5–8 是舒服区间**，不建议超过 12

### 3.3 Rerank（重排）

**它干什么**：Top K 是"粗筛"——只看文字表面像不像。Rerank 是"精排"——它会真的读一遍，判断"这段对这个问题到底有没有用"。

**打个比方**：

- **Top K** = 图书馆按书名关键词给你捞出 15 本书
- **Rerank** = 一个懂行的人翻了翻这 15 本，挑出真正对口的 5 本

**开不开**：

| 情况                     | 建议               |
| ---------------------- | ---------------- |
| 库小（几十份）、卡片边界清晰         | **可以不开**（本库就是这种） |
| 库大（几百上千份）、问答经常答偏       | 建议开              |
| 想用大 Top K（比如 20）再收紧到 5 | 必须开              |

**开的话要注意**：Rerank 是**另一个模型**，要单独配、单独跑一次，**比不开慢**。而且配错了会比不开更差。

**本库建议**：**先关**。41 份、38 张卡、每张卡开头就写明"我答什么"，边界已经很清楚，粗筛就够。跑完测试如果发现"检索到了不相干的卡"，再考虑开。

### 3.4 温度（Temperature）

**它干什么**：控制模型写答案时的**随机程度**。

**温度低（0.0–0.3）**：模型每次都挑"最可能的那个词"，输出稳定、保守、可复现。同一个问题问两遍，答案基本一样。

**温度高（0.7–1.0）**：模型会挑一些"不那么可能但也不错"的词，输出更有变化、更"活"，但**也更容易跑偏、编造**。

**你这个库该填多少**：**0.2**。

理由很直接——**你卖的是"照条文答"，不是"聊得有文采"**。温度高了对这种场景只有坏处：

- 同一道题两次答案不一样 → 买家以为你在糊弄
- 容易把"待核实"说成"已确定"
- 容易多加一句自己发挥的话，而那句话恰好是错的

> 💡 **DeepSeek 官方对数据类任务（抽取、分类、法规查询）的建议是 0.0**。填 0.1–0.3 都行，**别超过 0.5**。
>
> ⚠️ **温度调到 0 也不是 100% 确定**——GPU 浮点运算和并行批处理仍会带来微小差异。要绝对复现，得设 `seed` 参数（Cherry Studio 界面里不一定开放）。**所以验收表里要写清"同题两次结果可能略有措辞差异，但结论应一致"。**

## 四、常见误区（这几条最容易踩）

| 误区                         | 事实                                                            |
| -------------------------- | ------------------------------------------------------------- |
| **"知识库文件越多，AI 知道得越多"**     | ❌ 不是。多出来的是**检索噪音**。本库 41 份，正合适——每个主题一张卡，边界清晰                  |
| **"把法条原件也传进去，AI 就能核对条文了"** | ❌ 相反。原件里同一句话在多份文件重复，会占满 Top K 名额，把该命中的卡挤出去。**原件给人看，卡片给 AI 看** |
| **"温度调到 1 会更有创造力"**        | 法规问答不需要创造力，需要**不瞎编**。填 0.2                                    |
| **"换了 Embedding 模型效果会更好"** | 换了必须重新向量化，且中文场景 `bge-m3` 已经够。**没有明确理由不要换**                    |
| **"开了 Rerank 一定更准"**       | 不一定。配错模型、库又小，可能反而更差。**先测再开**                                  |
| **"这是训练，训练完就好了"**          | ❌ Cherry Studio 做的是 **RAG（检索增强）**，**模型权重一个字节都没变**。换个模型，效果就变   |

## 五、这个库的推荐配置（可直接抄进验收表）

```
载体：Cherry Studio
Embedding：bge-m3
Rerank：关闭（41 份库，暂不需要）
Top K：8（调优区间 5–10）
温度：0.2
检索池文件数：41（A1–A3 共 3 份 + B00–B38 共 38 张）
```

> **为什么 Rerank 关还能准**：这 38 张卡是**按"用户会怎么问"写的**，不是按法条章节写的。提问和卡片的措辞本来就接近，粗筛命中率就很高——这是本库刻意做的结构，不是运气。

## 六、调完之后要做什么

改参数不是目的，**验证**才是。改完请按 `D2_测试方法与判分标准.md` 第四节跑 14 道题：

1. **开全新对话**（不带历史）
2. **原话照问，一个字不加**——不要提示它"这是工伤问题"或"查一下知识库"
3. **每题单独开对话**，不连续追问
4. 记录：题目 / 回答原文 / 判 P-W-F / 依据里有没有列内部文件

**合格线**：14 题通过 ≥13 题（≥90%），拒答题（C10）必须 100% 拒答，依据不得出现库外条号。
