# 河南工伤保险政策知识库 · 项目成果（2026-10-28）

> 这是一个**可复现的项目记录**：38 张知识卡、54 份权威原件、43 份条文文本、100 题内部验收、30 题 A/B/C 对照。
> 它**不是商品交付包**，也**不是“准确率 100%”的产品**；它记录的是“怎么做、做完发现什么、哪些判断被推翻”。

**适用地区**：河南省
**法规/资料截止**：2026-10-28
**项目状态**：收尾归档；不再按“交付包”维护，保留为可复现案例。

---

## 一、这个项目做了什么

1. 把 54 份工伤政策原件按效力分级，做 PDF 存证 + 纯文本双份；
2. 写成 38 张九字段知识卡 + 3 份规则文件；
3. 只把 41 份整理层放进检索库，原件不进库；
4. 用 100 题做内部验收（96→98→100）；
5. 另建 30 题留出集，做 A（无库）/ B（原文 RAG）/ C（卡片库）对照；
6. 把发现的问题回写到卡片、规则、提示词；
7. 把过程、原始回答、结论全部留在仓库里。

---

## 二、关键结果（含反直觉）

| 测试 | 结果 | 怎么读 |
|---|---|---|
| 100 题内部验收 | **100P / 0W / 0F** | 内部验收；2 题评分标准在测试中修正，2 处格式待统一；**不是外部准确率** |
| 30 题 A/B/C | A ~22P、B ~24P、C ~24P（粗判） | **没有一组全面胜出**；差距在“错在哪类题” |
| 卡片 vs 原文 | B 只传 40 份原文，很多题已够用 | 卡片的增量集中在**边界/陷阱/本地数字** |
| 模型 vs 知识库 | A 在 Q9/Q15 反而答对 | **不维护的库，可能比不用库更危险** |

**最重要的结论**：

> 知识卡是产品外壳，不是知识权威；权威是新鲜的原文、准确的边界、可复现的验收，以及有人对过期负责。

完整结论见 `08_方法与复盘/方法论总结_V2_20261028.md`。

## 五、已知限制

1. **100P 是内部验收**：题、卡、判分同源，没有外部人工评审；
2. **模型依赖**：换模型/参数，结果会变；
3. **B 组未用新增资料重跑**：B 组跑的是 40 份实质条文；新增 C22/E6 后为 42 份；
4. **卡片会过期**：B38/B35 已经发生过一次，靠基线才发现；
5. **输出仍有工具痕迹**：C 组会出现 `[cite:...]`、过程话；D1 已加硬规则，`clean_output.py` 兜底；
6. **官方原件版权**：公开仓库包含政府公开文件，转载前请自行确认；不构成法律意见。
